## 一、本库定位

游戏上线后翻车，九成不是"玩法不够好"，而是**底下那层地基塌了**——
刷钱、越权、多端不一致、并发竞态、回档丢数据。这些坑一旦上线被黑/被刷，
损失不可逆（经济崩盘、口碑崩盘）。本库就是要把地基上每一个容易踩的坑
**先声明出来**，让"查漏"从碰运气变成**对表逐一排查**。

> 原则：**先声明，后检查；发现即沉淀，沉淀即复用。**

## 五、使用方式（各 Agent 自查清单）

开发/评审/测试任何服务端或跨端模块前，先对表：
1. **钱**：所有 `credit/debit/transfer` 是否校验 `amount>0`？是否有幂等/审计？
2. **权**：每个操作是否校验 `caller` 与资源 `owner` 一致？
3. **一致**：每个确定性计算是否走中间件统一函数（同 seed 同输出）？
4. **并发**：同一玩家/同物品的并发操作是否加锁/乐观锁？
5. **信任**：所有输入是否校验范围/类型/上限，还是直接信任客户端？
6. **存**：关键账本是否落盘/有备份，会不会进程重启即丢？
