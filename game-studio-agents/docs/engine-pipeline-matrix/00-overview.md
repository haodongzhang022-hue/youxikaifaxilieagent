# 引擎分层 × 专业方向管线矩阵（Engine Pipeline Matrix）

> 版本: v1.0  
> 对齐 Issue #126：深化「引擎分层 + 专业方向管线」架构，替代当前统一笼统输出  
> 核心命题：**不同引擎层级 → 不同专业管线 → 各管线独立优化 → 能力上限持续提升**

---

## 一、背景与痛点

当前系统的游戏开发输出是**统一笼统式**：无论目标是纯网页、Cocos 小程序、
Unity 客户端还是 UE 高保真，都用同一套部门 + 岗位去「一次性产出」。
这导致：

| 痛点 | 表现 | 根因 |
|------|------|------|
| 输出质量参差 | 同一需求在不同引擎下产出效果差距大 | 未区分引擎能力边界 |
| 管线不专业 | 角色动作、AI逻辑、场景特效混在一个工作包 | 未按专业方向拆分管线 |
| 无法深度优化 | 骨骼绑定、K动画、法线贴图等无法细分 | 美术管线深度不足 |
| 能力不积累 | 每个项目从零开始，复用低 | 无管线级知识沉淀 |

**目标**：建立**「引擎 × 专业方向」二维管线矩阵**——每个单元格是一条独立、
可追踪、可优化的开发管线，替代当前「一刀切」式输出。

### 2.2 核心原则

1. **每个单元格是一条独立管线**——有自己的输入、工作流、产出物、工具链、质量门禁
2. **引擎决定管线的深度**——L1 不需要骨骼绑定，L4 必须有
3. **专业方向决定管线的性质**——角色动作管线 ≠ AI 触发器管线
4. **管线独立可追踪**——每条管线有独立状态机、可暂停、可优化
5. **能力持续积累**——每条管线有独立的知识库/资产库沉淀

## 三、四层级引擎管线定义

### 3.1 L1 纯网页（React/WASM）

**定位**：玩法验证 + 网页引流 + 快速分享  
**核心管线**：

| 管线 | 输入 | 工作流 | 产出物 | 工具链 |
|------|------|--------|--------|--------|
| 角色动作 | 角色设计稿 | CSS动画→Sprite→骨骼(可选)→集成 | CSS/Sprite动画资源 | CSS Animations / Lottie |
| AI触发器 | 玩法设计 | TS状态机→事件系统→集成 | TS逻辑模块 | Zustand / XState |
| 场景特效 | 特效需求 | Canvas绘制→Shader→粒子→验证 | Canvas特效 / WebGL Shader | PixiJS / Three.js |
| 数值策划 | 数值模型 | 公式定义→参数调优→平衡验证 | JSON数值表 | 纯TS公式库 |
| 难度优化 | 用户数据 | 数据分析→曲线调整→A/B验证 | 难度曲线配置 | 埋点 + 数据看板 |
| 玩法优化 | 玩法反馈 | Loop分析→手感调优→留存验证 | 玩法迭代 | Playtest |

### 3.2 L2 Cocos Creator

**定位**：小程序 + 轻量分享传播  
**核心管线**：

| 管线 | 输入 | 工作流 | 产出物 | 工具链 |
|------|------|--------|--------|--------|
| 角色动作 | 概念图 | 2D骨骼(Spine/DragonBone)→动作制作→集成 | .anim/.prefab资源 | Spine / DragonBone |
| AI触发器 | 玩法设计 | TS行为树→感知系统→集成 | TS AI模块 | 自研行为树 / FSM |
| 场景特效 | 特效需求 | 粒子组件→Shader→性能优化→集成 | .plist/.prefab特效 | Cocos Particle |
| 数值策划 | 数值模型 | 配置表→JSON→验证 | JSON配置表 | 数值公式库 |
| 难度优化 | 用户数据 | 动态难度→参数调优→验证 | 难度配置 | Cocos 动态调参 |
| 玩法优化 | 玩法反馈 | Loop分析→手感调优→验证 | 玩法迭代 | Playtest |
| 骨骼绑定 | 模型/图集 | 骨骼创建→权重→动画 | .skel/.prefab | Spine / DragonBone |

**定位**：完整地图/App客户端  
**核心管线**：

| 管线 | 输入 | 工作流 | 产出物 | 工具链 |

| 模型上色 | 模型 | 顶点色→贴图烘焙→验证 | 贴图+顶点色 | Substance Painter |

## 四、专业方向管线模型

每条管线统一遵循**六段式工作流**（专业方向 × 引擎无关的通用骨架）：

```
┌─────────────────────────────────────────────────────────────┐
│                    管线生命周期                              │
│                                                             │
│  ① 输入解析    ② 工具选择    ③ 执行制作    ④ 质量门禁       │
│  · 需求解析    · 引擎适配     · 管线执行     · 标准检查       │
│  · 素材准备    · 工具选型     · 中间产物     · 性能验证       │
│  · 约束识别    · 依赖检查     · 迭代优化     · 一致性校验     │
│                                                             │
│  ⑤ 产出交付    ⑥ 知识沉淀                                   │
│  · 格式校验    · 管线经验记录                                 │
│  · 版本登记    · 资产入库                                    │
│  · 验收提交    · 复用模板生成                                 │
└─────────────────────────────────────────────────────────────┘
```

### 4.1 管线能力域

| 能力域 | 定义 | 跨引擎复用 | 引擎差异化 |
|--------|------|-----------|-----------|
| `character_animation` | 角色动作/动画 | 概念/风格/骨骼逻辑 | 工具链不同 |
| `ai_trigger` | AI触发器/行为逻辑 | 行为树设计/感知模型 | 引擎API不同 |
| `scene_vfx` | 场景特效 | 特效设计/节奏 | 粒子系统不同 |
| `numeric_design` | 数值策划 | 公式/参数/平衡 | 配置载体不同 |
| `difficulty_optimization` | 难度优化 | 曲线/公式/数据模型 | 数据接入不同 |
| `gameplay_optimization` | 玩法优化 | Loop/手感/反馈 | 引擎API不同 |
| `skeleton_binding` | 骨骼绑定 | 骨骼层级/权重分配 | 绑定工具不同 |
| `model_generation` | 模型生成 | Tripo/拓扑/UV | 导入格式不同 |
| `texture_material` | 纹理材质 | 贴图/材质逻辑 | 渲染管线不同 |
| `director_booth` | 导演台 | 镜头/灯光/叙事 | Timeline工具不同 |

### 4.2 管线注册表（Registry）

每条管线通过**统一注册表**登记，包含：

```yaml
pipeline_id: "pipeline.character_animation.unity"
name: "Unity角色动作管线"
engine: "unity"
domain: "character_animation"
status: "active"
inputs: ["绑定模型", "动作需求", "风格规范"]
workflow: ["K动画", "Clip制作", "状态机", "集成验证"]
outputs: [".anim", ".controller"]
tools: ["Unity Animator", "Timeline"]
quality_gates: ["动作流畅度", "性能基准", "风格一致性"]
knowledge_base: "角色动作管线的经验/模板/资产"
```

## 五、导演台（Director Booth）能力

导演台是**跨引擎的过场动画/叙事编排工作台**，借鉴视频创作流程：

### 5.1 核心能力

| 能力 | 说明 | 视频创作类比 |
|------|------|-------------|
| **时间轴编排** | 多轨道事件编排（角色/相机/灯光/音效） | 视频剪辑时间线 |
| **镜头控制** | 相机运动/景深/取景 | 摄影/摄像 |
| **灯光设计** | 灯光布局/阴影/色调 | 布光 |
| **角色表演** | 角色动作/表情/对白 | 演员表演 |
| **音效混音** | 背景音/音效/对白同步 | 混音 |
| **过场控制** | 播放/暂停/跳过/分支 | 剪辑/导演 |

### 5.2 各引擎实现

| 引擎 | 工具 | 能力对齐 |
|------|------|---------|
| L1 React | 自定义 Timeline（Web） | CSS/Canvas/WebGL 时间轴 |
| L2 Cocos | Animation Editor | Cocos 动画编辑器 |
| L3 Unity | Timeline | 多轨道/过场/相机 |
| L4 UE | Sequencer | 最完整/电影级 |

### 5.3 与视频创作流程的映射

```
视频创作流程                    导演台能力
─────────────                  ─────────────
分镜脚本          →            镜头蓝图 / Shot List
拍摄             →            角色表演 + 相机控制
剪辑             →            时间轴编排 + 多轨道
调色             →            灯光 + 后期特效
配音/音效         →            音频轨道 + 混音
成片输出          →            过场预览 + 导出
```
