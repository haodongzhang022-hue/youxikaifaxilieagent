> 版本: v1.0

## 一、角色动作管线（Character Animation）

### 1.1 引擎差异

| 维度 | React | Cocos | Unity | Unreal |
|------|-------|-------|-------|--------|
| 动作类型 | 2D CSS/Sprite | 2D骨骼 | 3D骨骼 | 3D骨骼 |
| 绑定方式 | N/A | Spine/DragonBone | Avatar Rig | Skeletal Mesh |
| 动画制作 | CSS动画 | Spine/DragonBone | K动画 | K动画 |
| 状态管理 | React状态 | Animation Controller | Animator Controller | AnimBlueprint |
| 产出物 | CSS/Lottie | .anim/.prefab | .anim/.controller | .uasset |

### 1.2 Unity 角色动作管线详细流程

```
输入: 绑定模型 + 动作需求 + 风格规范
 │
 ▼
[1] K动画制作
 │  - 关键帧设计
 │  - 中间帧插值
 │  - 曲线调整
 ▼
[2] Animation Clip 制作
 │  - 动作切割/命名
 │  - 循环设置
 │  - 曲线优化
 ▼
[3] Animator Controller
 │  - 状态机搭建
 │  - 参数定义
 │  - 转换条件
 ▼
[4] 集成验证
 │  - 游戏内预览
 │  - 性能基准
 │  - 风格一致性
 ▼
输出: .anim + .controller + 动画蓝图
```

### 1.3 UE 角色动作管线详细流程

```
输入: 绑定模型 + 动作需求 + 风格规范
 │
 ▼
[1] K动画制作（UE Animation Editor）
 │  - 关键帧/骨骼操作
 │  - 曲线调整
 ▼
[2] Animation Sequence
 │  - 动作切割/命名
 │  - 循环/非循环设置
 ▼
[3] Blend Space
 │  - 方向/速度混合
 │  - 权重调整
 ▼
[4] Animation Blueprint
 │  - 状态机
 │  - 事件驱动
 │  - 插槽系统
 ▼
[5] 集成验证
输出: .uasset 动画资产
```

## 二、AI 触发器管线（AI Trigger）

### 2.1 引擎差异

| 维度 | React | Cocos | Unity | Unreal |
|------|-------|-------|-------|--------|
| 行为实现 | TS状态机 | TS行为树 | C#行为树 | C++/BP行为树 |
| 感知系统 | 简单检测 | 碰撞检测 | NavMesh + 视觉 | Perception System |
| 寻路 | N/A | 简单寻路 | NavMesh | NavMesh |
| 高级AI | 简单决策 | FSM | GOAP | GAS + Behavior Tree |
| 产出物 | TS模块 | TS模块 | C#模块 | 行为树资产 |

### 2.2 管线工作流（以 Unity 为例）

```
输入: AI行为设计 + 战斗策划 + 关卡设计
 │
 ▼
[1] 行为树设计
 │  - 行为节点定义
 │  - 决策逻辑
 │  - 条件分支
 ▼
[2] 感知系统
 │  - 视觉/听觉/触觉
 │  - 感知范围/角度
 │  - 优先级
 ▼
[3] NavMesh
 │  - 导航网格生成
 │  - 寻路算法
 │  - 避障
 ▼
[4] 集成验证
 │  - 行为覆盖率
 │  - 帧率影响
 │  - 可调试性
 ▼
输出: C# AI模块 + 行为树配置
```

## 三、场景特效管线（Scene VFX）

### 3.1 引擎差异

| 维度 | React | Cocos | Unity | Unreal |
|------|-------|-------|-------|--------|
| 粒子系统 | Canvas粒子 | Particle组件 | Particle System | Niagara/Cascade |
| Shader | WebGL | 2D Shader | Shader Graph | Material Graph |
| 特效类型 | 2D | 2D/3D | 3D | 3D |
| 性能控制 | 粒子数限制 | 组件控制 | VFX Graph | Niagara性能 |

### 3.2 管线工作流（以 UE Niagara 为例）

```
输入: 特效需求 + 世界观 + 性能约束
 │
 ▼
[1] 特效构思
 │  - 视觉概念
 │  - 风格匹配
 │  - 节奏设计
 ▼
[2] Niagara 粒子系统
 │  - 粒子发射器
 │  - 粒子属性
 │  - 模块化设计
 ▼
[3] 材质 + Shader
 │  - 特效材质
 │  - 纹理
 │  - 混合模式
 ▼
[4] 性能优化
 │  - 粒子数限制
 │  - LOD
 │  - 渲染优化
 ▼
[5] 集成验证
输出: .uasset 特效资产
```

## 四、美术深度管线（Unity/UE）

### 4.1 模型生成管线（Tripo 等 AI 工具）

```
输入: 概念图 + 技术规范
 │
 ▼
[1] Tripo 生成
 │  - 文本/图片 → 3D模型
 │  - 多角度生成
 │  - 筛选最佳
 ▼
[2] 拓扑优化
 │  - 减面/重拓扑
 │  - 四边形/三角形
 │  - LOD 准备
 ▼
[3] UV 展开
 │  - UV 分布
 │  - 纹理空间优化
 ▼
[4] 导出验证
 │  - 格式转换 (.glb/.fbx)
 │  - 导入引擎验证
 │  - 面数/顶点数检查
 ▼
输出: 3D 模型资产
```

### 4.2 模型上色管线

```
输入: 模型 + 风格规范
 │
 ▼
[1] 顶点色设置
 │  - 颜色分区
 │  - 边缘色
 │  - 渐变过渡
 ▼
[2] 贴图烘焙
 │  - 颜色贴图烘焙
 │  - AO 烘焙
 │  - 光照贴图
 ▼
[3] 上色验证
 │  - 颜色准确性
 │  - UV 对齐
 │  - 风格一致性
 ▼
输出: 上色模型 + 贴图
```

### 4.3 法线贴图管线

```
输入: 高模 + 低模
 │
 ▼
[1] 高模烘焙
 │  - 高模法线采样
 │  - 切线空间转换
 │  - 细节提取
 ▼
[2] 法线提取
 │  - 法线贴图生成
 │  - 强度调整
 │  - 边缘处理
 ▼
[3] 映射验证
 │  - 低模应用
 │  - 视觉对比
 │  - 无接缝验证
 ▼
输出: 法线贴图
```

### 4.4 纹理材质管线

```
输入: 模型 + 贴图 + PBR 规范
 │
 ▼
[1] 纹理制作
 │  - 基础色 (Albedo)
 │  - 金属度 (Metalness)
 │  - 粗糙度 (Roughness)
 │  - 环境遮蔽 (AO)
 ▼
[2] 材质球创建
 │  - PBR 材质球
 │  - 节点连接
 │  - 参数调节
 ▼
[3] 渲染验证
 │  - 光照测试
 │  - 远近距离
 │  - 多角度
 ▼
输出: 材质资产
```

## 五、导演台管线（Director Booth）

### 5.1 核心工作流（以 Unity Timeline 为例）

```
输入: 分镜脚本 + 场景 + 角色 + 音频
 │
 ▼
[1] 镜头蓝图
 │  - 镜头列表
 │  - 每镜头时长
 │  - 相机位置/角度
 ▼
[2] Timeline 搭建
 │  - Playable Director
 │  - 轨道创建
 │  - 事件绑定
 ▼
[3] 轨道编排
 │  - 角色动画轨道
 │  - 相机轨道
 │  - 音频轨道
 │  - 字幕/对白轨道
 ▼
[4] 表演导演
 │  - 角色动作选择
 │  - 表情控制
 │  - 站位调度
 ▼
[5] 灯光设计
 │  - 灯光轨道
 │  - 色调/氛围
 │  - 阴影
 ▼
[6] 预览调优
 │  - 实时预览
 │  - 节奏调整
 │  - 性能验证
 ▼
输出: Timeline 资产 + 过场动画
```

### 5.2 UE Sequencer 导演台工作流

```
输入: 分镜脚本 + 场景 + 角色 + 音频
 │
 ▼
[1] Level Sequence 创建
 │  - 过场关卡
 │  - 场景引用
 ▼
[2] 轨道编排
 │  - Actor 轨道
 │  - Camera 轨道
 │  - Light 轨道
 │  - Audio 轨道
 ▼
[3] 相机导演
 │  - 多相机切换
 │  - 运动轨迹
 │  - 景深/焦距
 ▼
[4] 角色表演
 │  - 动画绑定
 │  - 面部表情 (Live Link)
 │  - 对白
 ▼
[5] 后期
 │  - Post Process
 │  - 色调/特效
 │  - 渲染设置
 ▼
[6] 输出
 │  - 游戏内播放
 │  - 视频导出
输出: Level Sequence 资产
```
