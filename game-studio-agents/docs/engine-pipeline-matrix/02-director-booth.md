# 导演台（Director Booth）能力设计

> 版本: v1.0  
> 对齐 Issue #126：借鉴视频创作流程，构建跨引擎的过场动画/叙事编排能力

---

## 一、核心定位

导演台是**游戏过场动画/叙事编排的工作台**，类比视频创作流程中的
「导演剪辑室」。它让 AI Agent 像导演一样编排游戏中的角色表演、镜头运动、
灯光设计、音效混音，最终产出电影级的过场体验。

```
视频创作流程           →    导演台能力
─────────────                 ─────────────
分镜脚本/Storyboard    →    镜头蓝图（Shot List）
现场拍摄               →    角色表演 + 相机控制
视频剪辑               →    时间轴编排 + 多轨道
调色/后期              →    灯光 + 后期特效
配音/音效              →    音频轨道 + 混音
成片输出               →    过场预览 + 导出
```

## 二、能力矩阵

### 2.1 通用能力（跨引擎）

| 能力 | 说明 | 视频创作类比 |
|------|------|-------------|
| **镜头蓝图** | 设计过场中的镜头列表（Shot List），每镜头含相机位置/角度/时长 | 分镜脚本 |
| **时间轴编排** | 多轨道事件编排（角色/相机/灯光/音效/对白/字幕） | 剪辑时间线 |
| **角色表演** | 控制角色动作/表情/对白/站位，含入场/退场/互动 | 演员表演 |
| **相机控制** | 相机运动轨迹/景深/焦距/视口切换 | 摄影 |
| **灯光设计** | 灯光布局/阴影/色调/氛围 | 布光 |
| **音效混音** | 背景音乐/音效/对白同步/音量平衡 | 混音 |
| **过场控制** | 播放/暂停/跳过/分支选择 | 播放控制 |
| **版本管理** | 过场版本迭代/对比/回滚 | 剪辑版本 |

### 2.2 各引擎实现

| 引擎 | 工具 | 能力完整度 | 特色 |
|------|------|-----------|------|
| L1 React | 自定义 Timeline | ★★☆ | Canvas/CSS/WebGL 编排 |
| L2 Cocos | Animation Editor | ★★☆ | 轻量过场 |
| L3 Unity | Unity Timeline | ★★★★ | 多轨道完整能力 |
| L4 Unreal | UE Sequencer | ★★★★★ | 电影级/最高能力 |

### 2.3 导演台管线注册

每条引擎的导演台能力注册为独立管线：

| pipeline_id | 引擎 | 工具 | 产出物 |
|------------|------|------|--------|
| `pipeline.director_booth.react` | React | 自定义 Timeline | Timeline配置/过场动画 |
| `pipeline.director_booth.cocos` | Cocos | Animation Editor | 动画配置/过场 |
| `pipeline.director_booth.unity` | Unity | Unity Timeline | Timeline资产 |
| `pipeline.director_booth.unreal` | UE | Sequencer | Level Sequence |

## 三、导演台工作流

### 3.1 六步导演流程

```
┌─────────────────────────────────────────────────────────────┐
│                    导演台工作流                              │
│                                                             │
│  ① 分镜设计    ② 场景准备    ③ 轨道编排    ④ 表演导演       │
│  · 叙事脚本    · 场景加载    · 轨道创建    · 角色动作        │
│  · 镜头蓝图    · 角色就位    · 相机设定    · 表情/对白       │
│  · 节奏规划    · 灯光预设    · 音效挂接    · 站位调度        │
│                                                             │
│  ⑤ 预览调优    ⑥ 成片输出                                   │
│  · 实时预览    · 过场导出                                    │
│  · 节奏调优    · 版本登记                                    │
│  · 性能验证    · 资产入库                                    │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 关键决策点

| 决策点 | 需要确认 | 决策方 |
|--------|---------|--------|
| 镜头数量/时长 | 叙事节奏是否符合预期 | 导演台（AI）+ 主策划 |
| 角色动作选择 | 动作库是否覆盖需求 | 导演台（AI）+ 动画师 |
| 灯光方案 | 氛围是否达标 | 导演台（AI）+ 主美 |
| 音效选择 | 音效是否匹配情绪 | 导演台（AI）+ 音频设计师 |
| 过场时长 | 是否过长/过短 | 导演台（AI）+ 制作人 |

## 四、导演台与 AI 协作

### 4.1 AI 作为导演助理

| 任务 | AI 角色 | 能力 |
|------|---------|------|
| 叙事脚本 → 镜头蓝图 | 分镜设计师 | 从脚本提取场景/角色/动作 → 生成镜头列表 |
| 镜头蓝图 → 时间轴 | 编排师 | 自动生成时间轴轨道/关键帧 |
| 角色动作选择 | 动作匹配器 | 从动作库匹配最适合的动画 |
| 灯光方案生成 | 灯光师 | 根据氛围生成灯光配置 |
| 音效匹配 | 音效编辑器 | 从音效库匹配场景所需音效 |
| 预览验证 | 质检员 | 自动检查过场流畅度/穿帮/节奏 |

### 4.2 导演台模板

每个导演台管线积累**过场模板**（Shot Templates），按类型分类：

| 模板类型 | 用途 | 示例 |
|---------|------|------|
| 剧情过场 | 主线叙事 | 角色对话/环境介绍 |
| 战斗演出 | 战斗高潮 | 大招展示/战斗结算 |
| 转场过场 | 场景切换 | 从 A 场景到 B 场景 |
| 叙事闪回 | 回忆/幻象 | 角色记忆回放 |
| 片头/片尾 | 游戏包装 | 标题动画/结尾字幕 |

## 五、能力上限扩展机制

导演台能力通过以下机制**持续扩展上限**：

### 5.1 资产沉淀

| 资产类型 | 沉淀方式 | 复用性 |
|---------|---------|--------|
| 过场模板 | 模板库 | 同引擎复用 |
| 镜头预设 | 镜头库 | 跨引擎复用（概念层面） |
| 动作库 | 动作资源库 | 同引擎复用 |
| 灯光预设 | 灯光方案库 | 跨引擎复用（概念层面） |
| 音效库 | 音效资源库 | 跨引擎复用 |

### 5.2 经验积累

每次导演台执行完成，记录：

- 什么方案效果好 / 效果差
- 哪些节奏/镜头组合玩家反馈好
- 各引擎的能力边界和最佳实践
- 可复用的模板和预设

### 5.3 工具链升级

| 阶段 | 能力 | 说明 |
|------|------|------|
| v1 | 基础编排 | 时间轴 + 轨道 + 角色动作 |
| v2 | 智能编排 | AI 自动生成镜头蓝图/灯光方案 |
| v3 | 电影级 | 镜头语言学习/复杂相机运动 |
| v4 | 程序化导演 | 根据叙事自动生成完整过场 |

## 六、与视频创作流程的深度对齐

### 6.1 术语映射

| 视频创作 | 导演台 | 游戏领域 |
|---------|--------|---------|
| 分镜脚本 | Shot List | 镜头蓝图 |
| 剪辑师 | 编排师 | 时间轴操作 |
| 摄影指导 | 相机导演 | 相机控制 |
| 灯光师 | 灯光导演 | 灯光设计 |
| 混音师 | 音频导演 | 音效混音 |
| 制片人 | 制作人 | 过场排期 |
| 成片 | 过场输出 | 游戏内过场 |

### 6.2 流程对齐

```
视频创作:
  剧本 → 分镜 → 拍摄 → 剪辑 → 调色 → 混音 → 成片

导演台:
  叙事脚本 → 镜头蓝图 → 轨道编排 → 角色表演 → 灯光/特效 → 音效 → 预览 → 成片
```
