# wp_release_plan · 发版计划与里程碑

- **工作包**：wp_release_plan 发版计划与里程碑
- **部门**：项目管理
- **主责角色**：project_manager（项目经理·协调型）
- **模块**：release
- **产出物类型**：release_plan（发版计划）

## 一、里程碑规划

| 阶段 | 内容 | 前置条件 |
|------|------|---------|
| M1 内部测试 | 核心玩法可玩 + 战斗/剧情/关卡全链路 | 三大部门产出验收通过 |
| M2 封闭测试 | 邀请玩家试玩，收集反馈 | 内部测试通过 |
| M3 公测（软启动） | 小规模公测，验证服务器容量 | 封闭测试数据达标 |
| M4 正式上线 | 全量发布 + 运营启动 | 公测数据达标 + 运营方案就绪 |

## 二、发版检查单

- [ ] 策划 5 份设计文档验收通过
- [ ] 程序 5 份实现方案验收通过
- [ ] 美术 3 份美术方案验收通过
- [ ] 测试 2 份测试方案验收通过
- [ ] 发版门禁（release_gate）全部通过
- [ ] 市场预演数据达标
- [ ] 运营方案就绪

## 三、风险预案

- 上线后紧急回滚流程
- 服务器扩容预案（120% 容量预留）
- 崩溃/安全事件响应流程
