# wp_perf_test · 性能验收方案

- **工作包**：wp_perf_test 性能验收方案
- **部门**：测试线
- **主责角色**：auto_qa（自动化测试工程师·框架向）
- **模块**：testing
- **产出物类型**：perf_doc（性能测试方案）

## 一、性能指标基准

**帧率**：
| 场景 | 目标帧率 | 降级阈值 |
|------|---------|---------|
| 主城/大厅 | 60fps | 45fps |
| 战斗（30敌人） | 60fps | 40fps |
| BOSS 战 | 50fps | 35fps |

**加载时间**：
- 启动到可交互：< 3s
- 场景切换：< 2s
- 关卡数据加载：< 500ms

**内存**：
- 战斗场景：< 200MB
- 角色模型：< 50MB（含贴图）
- 特效粒子：< 100MB

**网络**：
- 战斗 tick 延迟：< 50ms（P99）
- 战斗同步带宽：< 20KB/s/玩家
- 服务器响应：< 100ms（P95）

## 二、自动化测试框架

**测试工具**：
- 客户端：Unity Test Framework + Performance Testing Extension
- 服务端：pytest + locust（压测）
- 端到端：Playwright（UI 自动化）

**测试场景**：
1. 冒烟测试：核心功能可运行（每次构建后）
2. 回归测试：关键路径每周自动跑
3. 压测：1000 并发连接模拟
4. 性能监控：Profiler 采集关键指标

## 三、验收标准

- 所有性能指标达到目标值
- 无阻塞级性能问题（内存泄漏/严重掉帧）
- 压测 1 小时稳定，无连接丢失
