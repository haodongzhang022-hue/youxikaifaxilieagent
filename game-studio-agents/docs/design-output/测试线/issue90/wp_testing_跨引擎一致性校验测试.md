## 一、校验目标

> **同一输入 → 同一输出**：跨引擎一致性是架构核心目标，校验器确保各引擎对同一 seed / 同一 C ABI 调用产生 hash 一致的结果。

## 二、一致性校验维度

### 2.1 C ABI 接口一致性

| 校验项 | 方法 | 工具 |
|--------|------|------|
| 接口签名一致性 | 各语言包装器（TS/C#/Python/C++）调用同一 C ABI | 编译期静态检查 |
| 返回值一致性 | 同一输入 → 各语言包装器返回同一结果 | 运行时断言 |
| 错误码一致性 | 统一错误码（0=成功）各端一致 | 错误注入测试 |
| 内存管理正确性 | create/destroy 配对，无泄漏无悬挂 | Valgrind / ASan |

### 2.2 程序化生成确定性校验

| 校验项 | 输入 | 预期输出 | 校验方法 |
|--------|------|---------|---------|
| 地形生成 | seed="terrain_001" | 四端产出 hash 一致 | sha256 比对 |
| 关卡布局 | seed="level_002" | 四端布局 hash 一致 | sha256 比对 |
| 资源分布 | seed="prop_003" | 四端分布 hash 一致 | sha256 比对 |
| 敌兵生成 | seed="enemy_004" | 四端 spawn 点 hash 一致 | sha256 比对 |
| 建筑布局 | seed="building_005" | 四端建筑配置 hash 一致 | sha256 比对 |

### 2.3 数值计算一致性

| 校验项 | 操作 | 容差 |
|--------|------|------|
| 定点数加法 | 同 int64 定点数相加 | bit 级一致 |
| 定点数乘法 | 同 int64 定点数相乘 | bit 级一致 |
| 定点数除法 | 同 int64 定点数相除 | bit 级一致 |
| 概率计算 | 同 seed 随机数序列 | bit 级一致 |
| 伤害计算 | 同属性+技能 → 同结算 | bit 级一致 |

### 2.4 中立资产一致性

| 校验项 | 方法 | 容差 |
|--------|------|------|
| 模型顶点数 | glTF vs 各引擎导入 | ≤2% 偏差 |
| 贴图色彩 | PNG vs 各引擎采样 | ΔE ≤3 |
| 动画时长 | glTF vs 各引擎动画 | ≤1帧 |
| 音频响度 | WAV vs 各引擎播放 | ≤1dB |
| 场景布局 | JSON vs 各引擎场景 | 坐标误差 ≤0.01 |

## 三、校验器架构

```
┌─────────────────────────────────────────────────┐
│           跨引擎一致性校验器（ConsistencyVerifier）│
│                                                   │
│  输入：test_case.json（统一测试用例定义）          │
│  输出：consistency_report.json（校验报告）        │
│                                                   │
│  工作流：                                          │
│  1. 定义 test_case（seed / 操作 / 期望 hash）     │
│  2. 分发到 4 引擎执行器（Web/Cocos/Unity/UE）     │
│  3. 收集各引擎输出 → 计算 hash                    │
│  4. 比对 4 引擎 hash → 生成一致性报告              │
└─────────────────────────────────────────────────┘
```


### 3.2 校验判定规则

```python
def verify_consistency(engine_results: dict) -> tuple[bool, str]:
    """校验 4 引擎输出一致性"""
    hashes = set(engine_results.values())
    if len(hashes) == 1:
        return True, "PASS: 4 引擎输出 hash 一致"
    else:
        mismatched = {k: v for k, v in engine_results.items() if v != max(hashes)}
        return False, f"FAIL: 引擎 {list(mismatched.keys())} 不一致"
```
