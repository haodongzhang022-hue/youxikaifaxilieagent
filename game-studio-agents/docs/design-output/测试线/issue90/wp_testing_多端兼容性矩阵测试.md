# wp_testing · 多端兼容性矩阵测试（auto_qa）

- **工作包**：wp_testing 跨平台回归/性能测试
- **部门**：测试线
- **主责角色**：auto_qa（自动化测试工程师·矩阵向）
- **模块**：testing / compatibility-matrix
- **产出物类型**：test_doc（多端兼容性矩阵测试方案）
- **场景**：Issue #90「跨平台架构增强」——建立 Web/Cocos/Unity/UE 四端兼容性矩阵，覆盖多平台/多设备/多浏览器/多分辨率

---

## 一、兼容性矩阵维度

### 1.1 引擎 × 平台矩阵

| 引擎 | 平台 | 设备类别 | 操作系统 | 浏览器/运行时 |
|------|------|---------|---------|-------------|
| **Web (React)** | 桌面浏览器 | PC | Windows/macOS/Linux | Chrome / Firefox / Safari / Edge |
| **Web (React)** | 移动浏览器 | 手机/平板 | iOS/Android | Safari iOS / Chrome Android |
| **Cocos** | 小程序 | 手机 | iOS/Android | 微信/支付宝/抖音小程序 |
| **Cocos** | 原生 | 手机 | iOS/Android | 原生 App |
| **Unity** | 桌面 | PC | Windows/macOS | 原生客户端 |
| **Unity** | 移动 | 手机 | iOS/Android | 原生客户端 |
| **UE5** | 桌面 | PC | Windows | 原生客户端 |
| **UE5** | 主机 | PS5/Xbox | 主机系统 | 主机运行时 |

### 1.2 分辨率矩阵

| 设备类型 | 分辨率范围 | 适配策略 |
|---------|-----------|---------|
| 手机竖屏 | 375×667 ~ 430×932 | 响应式布局，竖屏优先 |
| 手机横屏 | 667×375 ~ 932×430 | 横屏模式切换 |
| 平板 | 768×1024 ~ 1024×1366 | 平板布局断点 |
| 桌面 | 1280×720 ~ 2560×1440 | 桌面全屏/窗口 |
| 主机电视 | 1920×1080 / 3840×2160 | 4K 高清渲染 |

### 1.3 性能等级矩阵

| 性能等级 | 设备示例 | 渲染规格 | 适配策略 |
|---------|---------|---------|---------|
| 低端 | 2GB RAM 手机 | 1280×720 / L0 资源 | 降级 L1→L0，降低粒子/阴影 |
| 中端 | 4GB RAM 手机 | 1920×1080 / L0+L1 | 标准渲染 |
| 高端 | 8GB RAM 手机/PC | 2560×1440 / L1+L2 | 全效果 |
| 旗舰 | 16GB+ RAM / 主机 | 4K / L2 资源 | 全高保真 |

## 三、自动化执行框架

### 3.1 执行架构

```
┌─────────────────────────────────────────────┐
│       多端兼容性测试自动化框架                  │
│                                               │
│  ┌─────────────┐  ┌──────────────────────┐  │
│  │ Test Runner │→│ WebDriver/Selenium    │  │
│  │ (CI 触发)   │→│ Appium (移动)          │  │
│  │             │→│ 小程序自动化 SDK       │  │
│  │             │→│ 引擎测试框架           │  │
│  └─────────────┘  └──────────────────────┘  │
│        │                                     │
│        ▼                                     │
│  ┌──────────────────────────────────────┐   │
│  │ CompatibilityMatrix 测试引擎         │   │
│  │ · 平台探测 → 设备指纹                 │   │
│  │ · 用例分发 → 按平台执行               │   │
│  │ · 结果汇总 → 兼容性报告               │   │
│  └──────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
```

### 3.2 CI 集成策略

| CI 阶段 | 触发时机 | 覆盖矩阵 |
|---------|---------|---------|
| 冒烟级 | 每次 PR | Web(Chrome) + Cocos(Android) 核心冒烟 |
| 回归级 | 每日 | Web(全部浏览器) + Cocos(iOS/Android) + Unity(桌面) |
| 全量级 | 每周 | 全部 8 平台组合全量兼容性回归 |
| 发布级 | 版本发布前 | 全量 + 性能 + 一致性联合验证 |

### 3.3 报告格式

```
多端兼容性矩阵测试报告 · <日期>
─────────────────────────────────────
覆盖矩阵：<平台> × <浏览器/设备> = N 种组合
执行用例：X / 通过 Y / 失败 Z / 跳过 W
通过率：NN.N%
兼容性问题：
  - 平台 <P>：<问题描述>（等级）
  - ...
结论：✅ 兼容 / ⛔ 存在兼容性问题
─────────────────────────────────────
```
