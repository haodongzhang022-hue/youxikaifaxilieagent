- MVP 落地路径骨架 + 下游输入（美术画质基线 / PM 排期门禁）

**关键设计要点**：
1. 本包为「方案储备」，不在 MVP 全量硬做云渲染，真云渲染留 UE 阶段兑现（阶段合规）
2. 核心三件套：协议先行 + 带宽感知调度 + 无缝接管，全部设计为跨引擎「永远复用资产」
3. 双管线与既有单向迁移线并存不推翻，对外发布矩阵共享同一套协议
4. 三套协议 IDL 边界本包已锚定，跨引擎各端据此生成绑定，切换下载互不推翻
