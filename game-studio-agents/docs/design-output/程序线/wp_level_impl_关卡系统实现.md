# wp_level_impl · 关卡系统实现

- **工作包**：wp_level_impl 关卡结构/难度曲线实现
- **部门**：程序线
- **主责角色**：engine_dev（关卡引擎）+ tools_dev（关卡工具链）
- **模块**：level_impl
- **产出物类型**：code（技术实现文档 + 代码骨架）

## 一、关卡框架实现（engine_dev）

### 1.1 关卡结构
- **LevelManager**：关卡状态机（Loading → Exploring → Combat → Settlement）
- **SceneLoader**：场景加载/卸载（7 大浮空大陆 = 7 大章节）
- **LevelData**：关卡声明化配置（探索区/战斗区/结算区三段式布局）

### 1.2 关卡功能
- **EnvironmentSystem**：环境机关（可破坏物/移动平台/能量门）
- **CoverSystem**：掩体/高低差系统（影响走位与技能命中）
- **HiddenPathSystem**：隐藏通路（宝箱/稀有材料奖励探索）
- **NarrativeTrigger**：剧情触发点（与叙事系统联动）

### 1.3 战斗区域
- **EncounterSystem**：战斗波次管理（1~3 波敌人 + 精英遭遇）
- **SpawnSystem**：敌人生成/重生点管理
- **CombatZone**：战斗区域边界与状态控制

## 二、难度曲线实现（tools_dev + engine_dev）

### 2.1 难度曲线数据
| 章节 | 敌人强度 | 战斗密度 | 解谜复杂度 | 玩家等级 |
|------|---------|---------|-----------|---------|
| 序章 | ★ | 低 | 无 | 1-5 |
| 第一章 | ★★ | 中低 | 低 | 5-12 |
| 第二章 | ★★★ | 中 | 中 | 12-20 |
| 第三章 | ★★★★ | 中高 | 中 | 20-30 |
| 第四章+ | ★★★★★ | 高 | 高 | 30+ |

### 2.2 难度平滑
- 相邻关卡强度差 ≤ 15%，避免断崖
- 每章节末尾 Boss 为峰值，带「教学-练习-实战」三段缓冲
- 死亡惩罚温和，重试后提供「降低弹反难度」等软保底

### 2.3 动态难度
- **DynamicDifficulty**：根据玩家表现动态微调敌人强度
- **RetryDebuff**：重试降难机制（惩罚递减）

## 三、工具链实现（tools_dev）

### 3.1 关卡编辑器
- **LevelEditor**：关卡可视化编辑工具
- **ValidationTool**：关卡白盒验证工具（寻路/可玩性/难度）

### 3.2 白盒验证
- **PathfindingCheck**：寻路验证（主要通路无卡死/无死胡同）
- **PlayabilityCheck**：战斗密度与跑图节奏平衡
- **DifficultyCheck**：用数值模型模拟不同等级玩家通关时长
