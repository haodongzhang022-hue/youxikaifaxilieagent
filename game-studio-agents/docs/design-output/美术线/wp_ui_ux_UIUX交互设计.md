# wp_ui_ux · UI/UX 与交互设计

- **工作包**：wp_ui_ux UI/UX 与交互设计
- **部门**：美术线
- **主责角色**：ui_ux（UI/UX设计师·体验向）+ tech_artist（技术美术·管线向）
- **模块**：ui_ux
- **产出物类型**：ui_asset（UI 设计文档）

## 一、UI 视觉体系（ui_visual）

### 1.1 设计语言
- **风格**：与「赛博星核 × 失落文明」整体风格对齐，冷蓝+暖金+暗紫三色体系
- **字体**：中文思源黑体（正文/UI 标准字体）+ 英文 Orbitron（标题/装饰）
- **图标语言**：线面结合，星核能量光效点缀，悬浮大陆轮廓隐喻
- **动效规范**：切换过渡 200ms ease-out，提示浮现 150ms fade-in，反馈震动 80ms

### 1.2 交互规范（interaction_spec）
- **导航**：扁平导航 + 面包屑，一级页面直达，二级以下用选项卡
- **反馈**：即时反馈原则——点击/悬停/拖拽均有视觉反馈（按下缩放 0.95、悬停高亮）
- **无障碍**：文字对比度 ≥4.5:1，触控目标 ≥44px，支持键盘/手柄导航

## 二、核心界面设计（core_ui）

### 2.1 战斗 HUD
- **布局**：左下体力槽、右下技能槽（3 技能+大招）、中央下方怒气槽、左上任务/目标提示
- **反馈设计**：受击红闪 150ms、技能冷却遮罩（灰度旋转）、大招充能发光条
- **信息密度**：HUD 同时显示元素 ≤8 个，关键信息始终可见

### 2.2 主界面（Menu）
- **布局**：主菜单四宫格（继续旅程/星械工坊/氏族社交/设置）
- **视觉**：全屏背景图（当前章节大陆视角）+ 动态星核光效背景层
- **交互**：悬浮缩放 + 点击光晕反馈，支持手柄/键鼠双输入

### 2.3 背包/星械界面
- **布局**：左侧物品列表（图标+名称+品质色）、右侧详情面板
- **品质色**：白<绿<蓝<紫<金（对齐数值模型掉落概率层级）
- **交互**：拖拽整理 + 右键快捷操作，支持排序/筛选/标记

### 2.4 任务/世界观界面
- **任务面板**：左侧章节任务树、右侧任务详情（目标/奖励/追踪按钮）
- **世界观图鉴**：七大氏族/角色/地点/星械 分类浏览，收集进度展示
- **交互**：点击条目展开详情，支持搜索/筛选/跳转任务

## 三、UI 组件库（ui_components）

### 3.1 通用组件
- **按钮**：主按钮（金边发光）/ 次按钮（冷蓝描边）/ 禁用态（降饱和）
- **弹窗**：磨砂玻璃背景 + 圆角 8px，关闭/确认/取消三键布局
- **进度条**：分段式 + 百分比文本，使用渐变填充（蓝→金）
- **图标集**：功能图标 40+（线性风格 + 彩色强调），全部 SVG 格式

### 3.2 布局栅格
- 基准栅格：1280×720（PC）/ 750×1334（移动端），适配 16:9 / 19.5:9
- 安全区域：屏幕边距 24px（PC）/ 16px（移动端），避开刘海/圆角

## 四、UI 实现对接（tech_artist）

### 4.1 UI 渲染管线
- **UI 框架**：对接程序线 UIFramework（HUD/菜单/商城/背包）
- **UI 资源**：Sprite Atlas 合图（单图集 ≤1024×1024，动态加载）
- **Shader**：UI 专用着色器（支持发光描边、磨砂玻璃、渐变填充），Shader 变体 ≤8

### 4.2 数据绑定
- **动态数据**：体力/怒气/金币/任务进度 实时从 GameplayCore 读取
- **静态数据**：物品/任务/氏族 从服务端 DataLayer 异步加载
- **事件驱动**：UI 状态变更由 message_bus 事件驱动（如背包物品变更触发刷新）

## 五、UI 验收标准

### 5.1 功能验收
- 所有页面可达：主菜单→（战斗/背包/任务/氏族/设置）跳转不超过 2 次点击
- 所有操作有反馈：点击/悬停/拖拽/错误均有视觉提示
- 多分辨率适配：PC 1280×720 ~ 2560×1440、移动 750×1334 ~ 1080×2400 无遮挡/溢出

### 5.2 性能验收
- 单界面 Draw Call ≤20，UI 图集内存 ≤64MB
- 界面切换无白屏/卡顿（异步预加载关键 UI）
- UI 动效帧率 ≥60fps
