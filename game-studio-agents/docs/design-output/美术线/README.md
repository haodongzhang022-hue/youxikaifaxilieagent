# 美术线 · 承接产出

> 场景：策划线设计 + 程序线实现方案验收通过后，下游解锁 → 美术线承接美术资产。
> 美术线部门统一头（art_director）承接，全程经协作工作台 @分工 留痕（group_audit）。

## 一、承接工作包

| 工作包 | 模块 | 主责角色 | 产出物 |
|--------|------|----------|--------|
| wp_concept_art | narrative + combat | concept_artist | 世界观/角色/怪物原画设定 |
| wp_character_model | combat | modeler | 角色/怪物 3D 模型资产 |
| wp_animation | combat | animator | 角色动作/战斗动画 |
| wp_vfx | combat | vfx_artist | 战斗特效/打击反馈 |
| wp_ui_visual | gameplay | ui_ux | 界面视觉/交互规范 |
| wp_scene_asset | level | concept_artist + modeler | 场景概念/关卡资产 |
| wp_audio | narrative | audio_designer | 剧情/战斗配乐音效 |

## 三、跨部门协作

| 协作方向 | 部门 | 协作内容 | 触发时机 |
|---------|------|---------|---------|
| 上游消费 | 策划线 | 消费世界观/角色/战斗设计 | 策划产出验收后 |
| 上游消费 | 程序线 | 消费战斗引擎/AI实现约束 | 程序实现方案确定后 |
| 下游解锁 | 测试线 | 对美术资源做兼容性/性能验收 | 美术资产交付后 |
| 联动 | 运营线 | 消费美术品质做市场预演 | 美术品质基准确定后 |
