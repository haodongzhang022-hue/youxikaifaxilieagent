# wp_art_direction · 美术风格与资源设计

- **工作包**：wp_art_direction 美术风格与资源
- **部门**：美术线
- **主责角色**：art_director（主美·品质向）+ concept_artist（原画）+ modeler（3D建模）+ animator（动画）+ vfx_artist（特效）+ tech_artist（技术美术）
- **模块**：art_direction
- **产出物类型**：art_doc（美术设计文档）

## 一、美术风格定义（style_guide）

### 1.1 整体风格定位
**「星穹守望者」** 采用 **「赛博星核 × 失落文明」** 融合风格：

- **基调**：科幻写实 + 神秘远古（浮空大陆、星械、虚空侵蚀）
- **色彩体系**：冷蓝为主色调（苍穹中枢），暖金点缀（星核能量），暗紫渲染（虚空侵蚀）
- **光影**：半现实光照 + 体积光强化（星核发光源），暗部保留冷调避免脏灰
- **粒子质感**：星核能量使用高光粒子 + 流动辉光，虚空侵蚀使用烟尘+腐蚀纹理

### 1.2 视觉基准（art_quality）
| 维度 | 基准值 | 说明 |
|------|--------|------|
| base_quality | 65.0 | 基础资源品质 |
| art_quality | 72.0 | 美术整体品质（中上水准） |
| art_sens | 0.2 | 泛玩家美术敏感度偏好 |

### 1.3 风格一致性
- 统一使用「棱角+曲线」混合造型语言（古代遗迹的几何感 + 星械的流线感）
- 七座浮空大陆各自有主色调变体，但共用一套材质语言（锈蚀金属/发泡岩石/能量晶体）
- 角色、场景、UI 共享同一色彩体系与光照方向

## 二、角色美术设计（character_art）

### 2.1 角色概念设计（concept_artist）

| 角色 | 视觉定位 | 设计要点 |
|------|---------|---------|
| 主角（守望者） | 成长型 | 初期朴素的古旧护甲 → 后期星械变形装甲，随成长弧光强化视觉 |
| 导师「伊芙」 | 睿智沉稳 | 银发 + 星核能量纹饰，长袍融入七氏族纹章 |
| 氏族领袖「卡恩」 | 强势豪迈 | 重甲 + 大剑，氏族图腾纹身，粗犷质感 |
| 虚空领主 | 悲情反派 | 被虚空侵蚀的半机械体，暗紫+红眼的腐蚀视觉 |

### 2.2 3D建模与贴图（modeler）
- **建模标准**：角色 30K~80K 面，场景主物体 100K~500K 面，道具 10K~30K 面
- **贴图规格**：角色 2048×2048 PBR，场景 4096×4096，道具 1024×1024
- **材质语言**：锈蚀金属（roughness 0.6~0.9）+ 发泡岩石（base color 冷灰）+ 能量晶体（自发光 + 半透明）

### 2.3 动作与动画（animator）
- **战斗动作**：对齐 combat 设计——攻击前摇 ≤0.15s，后摇可取消，闪避无敌帧 0.3s，弹反窗口 0.2s
- **动作风格**：写实灵动，受击反馈明确（命中停顿 60ms / 震屏幅度 0.5~1.0）
- **过场动画**：剧情关键节点使用 CutsceneDirector 演出（镜头调度 + 角色微表情）

### 2.4 特效设计（vfx_artist）
- **战斗特效**：星械变形使用高光粒子爆发；重击命中震屏+碎裂粒子；技能按职业区分色系
- **环境特效**：星核能量脉动光晕、虚空侵蚀腐蚀扩散、浮空大陆体积雾
- **性能控制**：单次特效粒子数 ≤500，单场景同时特效数 ≤20

## 三、场景美术设计（scene_art）

### 3.1 七大浮空大陆视觉主题
| 章节 | 大陆主题 | 主色调 | 视觉特征 |
|------|---------|--------|---------|
| 序章 | 苍穹中枢 | 冷蓝+白金 | 古代能源核心，悬浮平台，星核光柱 |
| 第一章 | 星烬平原 | 灰蓝+暗金 | 遗迹残骸，荒漠废土，漂浮碎岩 |
| 第二章 | 雾岚群岛 | 青灰+翠绿 | 云雾缭绕，浮岛植被，水晶矿脉 |
| 第三章 | 熔铁裂谷 | 赤红+黑铁 | 熔岩河流，锈蚀工厂，能量核心 |
| 第四章+ | 虚空边界 | 暗紫+冷白 | 虚空裂缝，腐蚀大地，异形植被 |

### 3.2 场景资源规格（modeler + tech_artist）
- 场景物件 LOD 3 级：LOD0（完整）/ LOD1（简化 50%）/ LOD2（极简 15%）
- 光照方案：实时方向光 + 烘焙静态光（Baked Lightmap）
- 性能目标：PC 端 ≥60fps、移动端 ≥30fps（tech_artist 保证管线优化）

## 四、技术美术规范（tech_artist）

### 4.1 渲染管线
- **渲染路径**：PBR 渲染（Metallic-Roughness 工作流）
- **Shader 标准**：统一 PBR 着色器 + 可变特性（自发光/半透明/折射），Shader 变体数 ≤20
- **后期处理**：Bloom（星核辉光）+ Vignette（暗角强化氛围）+ Color Grading（冷调 LUT）

### 4.2 资源管线
- 资产命名规范：`<类型>_<名称>_<版本>`（如 `character_hero_v01`）
- 资源压缩：贴图 ASTC 6x6（移动端）/ BC7（PC 端）
- 加载策略：AssetBundle 按场景分包，非关键资源异步加载

## 五、美术品质验收

### 5.1 视觉一致性检查
- 各大陆场景主色调与设计基准一致性 ≥95%
- 角色/场景/UI 色彩体系共享（统一 LUT 引用）
- 光照方向全场景统一（主要光源于天空/星核）

### 5.2 性能预算
- 单场景 Draw Call ≤500（PC）/ ≤200（移动端）
- 单角色骨骼数 ≤100，蒙皮顶点 ≤200K
- 场景三角面总量 ≤1M（PC）/ ≤500K（移动端）
