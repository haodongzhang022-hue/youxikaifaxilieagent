# wp_animation · 战斗动画方案

- **工作包**：wp_animation 角色动作/战斗动画方案
- **部门**：美术线
- **主责角色**：animator（动画师·写实向）
- **模块**：combat
- **产出物类型**：anim_doc（动画设计文档）

## 一、动画风格定位

**核心风格**：写实灵动 + 战斗表现力

- **写实性**：动作捕捉为基础，加入物理修正，保证动作真实感与质感
- **战斗张力**：攻击动作干净利落（前摇 ≤0.15s），受击反馈清晰（命中停顿 60ms）
- **手感优先**：对齐 combat 设计参数——后摇可取消、闪避无敌帧 0.3s、弹反窗口 0.2s

## 三、过场动画（Cutscene）

- **剧情关键节点**：序章苏醒、第一章试炼、第三章抉择、终章 BOSS
- **镜头调度**：对话特写→全景环境→战斗穿插，由 CutsceneDirector 控制
- **角色表现**：微表情系统（眨眼/眼神追踪）+ 语音口型同步

## 四、动作技术规格

- 动画文件：FBX 骨骼动画，采样率 30fps
- 根运动：位移由动画驱动（Root Motion），保证手感一致性
- LOD：远处动画降级（骨骼数减半、动画简化）
- 内存：单角色动画总内存 ≤16MB

## 五、验证指标

- 攻击前摇 ≤0.15s，后摇可取消验证
- 闪避无敌帧 0.3s 精确验证
- 动画切换无穿透/滑动（过渡 2 帧内完成）
- 过场动画加载 < 1s，无缝衔接
