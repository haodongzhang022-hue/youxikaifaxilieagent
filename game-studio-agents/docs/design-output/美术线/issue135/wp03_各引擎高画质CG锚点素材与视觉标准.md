## 二、CG 锚点视觉总纲（art_director · S-3.1）

### 2.1 CG 锚点角色定位（对齐策划 WP-01 漏斗②）

> CG 是**「画质锚点 + 云实例启动遮罩」**——低配玩家点「增强画质」后看到的第一画面。
> 它是「画质承诺」，需让玩家认知：**看到的画质 = 下载本地版后将体验的画质**，落差不可过大。

**CG 锚点三重目标**：
1. **承诺传达**：用 5-15s 高画质片段让玩家"被吸引、愿意下载"
2. **遮罩期**：掩盖云实例预热 5-15s，不让玩家觉得等待
3. **信任建立**：让玩家相信"下载本地版不会失望"

### 2.2 世界观「星穹守望者」CG 画质锚点框架

统一世界观下的**高画质展示核心三镜头**（对齐 issue126 色彩体系）：
- **镜头 A「苍穹中枢」**：冷蓝主调，巨型天穹空间站与星轨环形结构，展示体积光+大场景纵深
- **镜头 B「星核能量晶体」**：暖金点缀，手持能量晶体特写，展示材质细节/次表面散射
- **镜头 C「虚空侵蚀边界」**：暗紫渲染，被侵蚀的遗迹与星械对战前场，展示粒子/体积雾/战斗张力

### 2.3 四引擎 CG 锚点展示矩阵

| 锚点用途 | L0 网页 | L1 Cocos/小程序 | L2 Unity(团结) | L3 UE |
|---|---|---|---|---|
| 世界观开场锚点 | 序列帧 / 轻量 WebM 动画 | 2D 过场 + 低模 | 实时 Timeline 过场 | Sequencer 电影级 |
| 增强画质 CG（点击后 5-15s） | WebM 预渲染（≤3MB） | MP4 预渲染（≤10MB） | 预渲染 + 实时可选 | **实时渲染**（目标画质） |
| 无缝切换过渡 | 全屏 UI 过渡 + 存档提示 | 同左 | 同左 + 相机续位 | 同左（对齐切端） |
| 画质表达深度 | 构图/光影静态张力 | + 动态序列 | + 实机镜头 | + 实时材质体积光 |

> 关键设计：**L0/L1/L2 用预渲染 CG，L3 用实时渲染**。同一套世界观核心三镜头，母版在 UE 渲染高规格，
> 派生为各端规格（WebM 低码率 → MP4 中码率 → 实时引擎镜头蓝图），保证"同一世界、同一段承诺"。

### 2.4 画质承诺认知链（画质分级一致性）

| 层级 | 画质表现 | 认知定位 |
|------|---------|---------|
| CG 展示画质 | 最高（目标画质） | "这是下载后能达到的画质" |
| 云高配试玩 | 中高（接近CG，受网络约束） | "云端的画质与CG相近" |
| 本地轻量版 | 基础（当前玩到的） | "这是轻量入口，点增强可升级" |

> 护栏：CG 与云实机/本地实机需收敛，**落差不可超过 1 档**（对齐策划 WP-01 2.3 画质落差护栏）。
> 不夸大承诺：CG 展示的是**可在目标端实际达到**的画质，非概念图。

## 三、CG 母版派生管线（tech_artist · S-3.2）

### 3.1 CG 母版 → 各端多规格派生管线

```
UE 高规格母版渲染（4K, HDR）
    │
    ├──► 派生产物 A：L0 网页 WebM（≤3MB, 720p, 低码率 H.264）
    ├──► 派生产物 B：L1 Cocos MP4（≤10MB, 1080p, 中码率 H.265）
    ├──► 派生产物 C：L2 Unity 预渲染（20-50MB, 1080p, 高码率）+ 实时可选
    └──► 派生产物 D：L3 UE 实时渲染（Sequencer 镜头蓝图, 不落文件）
```

**派生规格约束**（对齐程序 WP-02 §5.3 下游输入）：

| 目标端 | 容器格式 | 码率上限 | 分辨率 | 时长 | 首帧加载目标 |
|--------|---------|---------|--------|------|------------|
| L0 网页 | WebM | ≤1.5Mbps | 720p | 5-15s | ≤2s 首帧 |
| L1 Cocos | MP4 | ≤4Mbps | 1080p | 5-15s | ≤2s 首帧 |
| L2 Unity | MP4 + 实时可选 | ≤10Mbps | 1080p | 5-15s | ≤1s |
| L3 UE | 实时 Sequencer | N/A（实时） | 4K/视口 | 5-15s | 无文件 |

### 3.2 无缝切换过渡的渲染方案（对齐程序 WP-02 §3.3）

> 程序线已定义：切换过渡 = 统一「传送门 / 电梯 / 黑屏淡入」遮罩 + 相机续位 + 前 30s 视角一致。
> 美术线给出**视觉表现标准**：

**过渡遮罩三套方案**：
1. **传送门方案（默认）**：全屏能量传送门亮起 → 白光扩散遮盖 → 新画质场景从门中展开。需 L0/L1 用序列帧，L2/L3 用实时粒子+着色器过渡。
2. **电梯下行方案（备选）**：画面四周暗角渐收 → 垂直降层效果 → 新画质从下方升起。降低对渲染资源要求，适合低端端。
3. **黑屏淡入方案（兜底）**：简版，仅做全屏快速黑场 + 新画质淡入，所有端可用。

**无缝衔接视觉护栏**：
- 前 30s 与云端视角一致：切换完成后的**首个镜头**需与玩家在云端看到的最后画面**同视角**（对齐程序 §3.3.4）
- 镜头续位：切换点画面中心位置不变，仅画质渐变提升（不能跳切）

### 3.3 CG 渲染与性能预算

| 指标 | L0 网页 | L1 Cocos | L2 Unity | L3 UE |
|------|:--:|:--:|:--:|:--:|
| CG 播放帧率 | 24fps | 30fps | 30fps | 实时60fps |
| 过渡特效 GPU 占用 | 无（纯视频） | ≤5% | ≤10% | ≤15% |
| 切换过渡时长 | ≤1.5s | ≤1.5s | ≤2s | ≤2s |
| 全链路（点增强→CG首帧） | ≤2s | ≤2s | ≤1.5s | ≤1s |

## 四、过场 CG 镜头语言与过渡动画方案（animator · S-3.3）

### 4.1 过场 CG 镜头语言设计

**核心三镜头分镜设计**：

**镜头 A「苍穹中枢」· 大场景俯冲**
```
镜头：缓慢俯冲 → 环绕 → 定格在空间站核心
时长：5s
节奏：慢速推镜（dolly-in）→ 中速环绕（orbit）→ 定格
情绪：庄严敬畏，展示宏大世界观
```

**镜头 B「星核能量晶体」· 特写**
```
镜头：微距推近 → 旋转展示 → 特写晶体光芒脉冲
时长：4s
节奏：缓推 → 自转展示 → 光芒脉冲节奏感
情绪：神秘珍贵，展示材质细节与能量体系
```

**镜头 C「虚空侵蚀边界」· 战斗张力**
```
镜头：粒子涌来 → 角色拔刃 → 快速剪辑 3-5 个动作节拍
时长：4-6s
节奏：快切 + 速度线 → 粒子爆发 → 角色特写收尾
情绪：紧张压迫，展示动作张力与 VFX 表现
```

### 4.2 角色微表情表演标准

- **角色特写**：微表情需在 CG 与实时引擎中一致性（眼睛焦点、嘴角张力、眉骨压迫）
- **情绪锚点**：每个核心角色有 3 个基准情绪微表情（冷静/震惊/坚定）
- **L0/L1 序列帧替代**：因低端无法做实时微表情，需在预渲染 CG 中预演出，派生为视频帧

### 4.3 切换过渡动画设计（传送门方案细化）

```
[玩家点击「增强画质」]
    │
    ▼
[CG 开场：暗角 + 能量粒子汇聚 → 屏幕中心亮起传送门光圈]
    │ (传送门开启 0.5s)
    ▼
[传送门扩散全屏(白光遮罩) → 新画质场景从白光中展开]
    │ (过渡 1-1.5s)
    ▼
[新画质场景首帧 = 与云端最后画面同视角]
    │ (前 30s 视角延续)
    ▼
[玩家感知：画质升级了，但世界没有变]
```

**动画调优**：
- 传送门扩散速度需匹配云实例就绪时间（若云端 2s 就绪则过渡可更快，若需 8s 则 CG 延长）
- 全部引擎用同一套过渡动画视觉语言，仅实现方式不同（L0 序列帧 / L1 骨骼动画 / L2 Timeline / L3 Sequencer+Niagara）

## 六、高画质定妆镜头概念设计（concept_artist · S-3.5）

### 6.1 三套定妆镜头概念帧描述

**镜头 A「苍穹中枢」概念**：
- **构图**：巨型空间站占画面中央偏下，镜头从远处 45° 俯冲，天空环带向两侧延伸
- **色彩**：冷蓝主调 + 远处暖金空间站核心光点 + 暗紫空间背景
- **细节**：建筑棱角+曲线混合（对齐造型语言），可见外舱门、轨道运输带、信号塔
- **光影**：光源来自左上方巨型恒星，形成长阴影 + 高光面反射

**镜头 B「星核能量晶体」概念**：
- **构图**：晶体占画面 2/3，微微偏右，光源从晶体后方透射形成剪影
- **色彩**：暖金主调 + 冷蓝环境光边缘 + 暗紫投影
- **细节**：晶体内部可见裂纹状能量纹路，表面有锈蚀+结晶混合纹理
- **光影**：内部发光形成次表面散射效果，周围浮尘粒子受光

**镜头 C「虚空侵蚀边界」概念**：
- **构图**：前景角色（拔刃侧身剪影）+ 中景侵蚀雾波 + 远景断裂空间站残骸
- **色彩**：暗紫主调 + 蓝色护盾光源 + 暖金武器能量点缀
- **细节**：角色武器折射蓝光，地面裂开露出紫色能量裂缝
- **光影**：冷暖对抗，护盾蓝光与侵蚀紫雾形成对比层次

## 八、UI「增强画质/下载」入口与切换界面规范（ui_ux · S-3.7）

### 8.1 「增强画质」入口 UI 设计

**触发条件**：玩家在本地轻量版（L0/L1）游玩中，系统检测到玩家有下载升级潜力（网络/设备适配）

**入口样式规范**：
- **位置**：游戏内悬浮按钮（右下角），设置页永久入口
- **文案**：「增强画质」（首次）→「下载完整版」（后续进度提示）
- **视觉**：金色光效渐变描边 + 微动效（呼吸脉冲），突出"升级感"而非"广告感"
- **首次触发**：特定剧情推进节点/等级达成后弹出，不打断核心玩法（侧边滑入）

**四引擎 UI 表现**：

| 目标端 | UI 实现 | 视觉规格 |
|--------|---------|---------|
| L0 网页 | HTML/CSS 动效 | 金色光晕描边 + 悬浮位移动效 |
| L1 Cocos | 骨骼 UI 动效 | 同上 + 粒子辉光 |
| L2 Unity | UGUI + Animation | 同上 + Shader 光效 |
| L3 UE | UMG + Sequencer | 同上 + 实时 Bloom + 泛光 |

### 8.2 下载进度与切换过渡界面

**下载进度浮层**：
- 从 CG 切换到云高配时，右下角出现**轻量进度条**（不遮挡游玩画面）
- 样式：细窄金色进度条 + 百分比数字，暗色半透明底
- 可点「暂停下载」/「继续下载」，点击后浮层展开操作选项

**无缝切换过渡界面（对接 §三 渲染方案）**：
- 过渡到本地时，传送门全屏遮罩 → 白光 → 新画质展开
- 过渡完成后显示简短 Toast：「完整版已就绪，画质已升级」

**UI 视觉护栏**：
- 「增强画质」不可使用弹窗/横幅强推（会给玩家"被塞广告"的不适感）
- 下载进度可视化必须**清晰易懂**，不用花哨的视觉掩盖进度实质
- 切换过渡不超过 2s，超时需降级为黑屏淡入（保证不卡死）

## 九、CG 过场配乐与切换音效（audio_designer · S-3.8）

### 9.1 CG 过场配乐体系

**音乐风格**：「星穹守望者」主题——电子合成 + 交响弦乐 + 异星环境音

| CG 锚点 | 音乐风格 | 情绪目标 |
|---------|---------|---------|
| 镜头 A「苍穹中枢」 | 交响弦乐 + 电子垫底 | 庄严史诗，宏大世界观震撼 |
| 镜头 B「星核晶体」 | 钢琴 + 低频正弦 + 晶体共鸣音色 | 神秘氛围，神秘珍贵感 |
| 镜头 C「虚空侵蚀」 | 打击乐加速 + 失真低频 + 弦乐急促 | 紧张战斗，压迫张力 |

**BGM 时长对齐**：每段 CG 配乐需严格对齐 CG 视频时长（5-15s），供 L0/L1 视频直接嵌入

### 9.2 切换过渡音效

| 过渡类型 | 音效设计 | 时长 |
|---------|---------|------|
| 传送门开启 | 能量汇聚嗡鸣 → 金属质感的"洞开"声 → 空间扭曲噪声 | 0.8-1.2s |
| 新画质展开 | 环境氛围音淡入 + 高频光洁感+低频厚重感叠加 | 1-2s |
| 画质提升感知 | 音高微妙上移 2 个半音 + 空间感增强（混响增大） | 过渡期间 |

**音频规格**：
- 主格式：WAV 48kHz/24bit（母带）
- L0 网页：MP3 128kbps / AAC 96kbps
- L1 Cocos：AAC 128kbps
- L2 Unity / L3 UE：WAV 或 OGG（无损/近无损）
