## 一、建模规范

**三角面预算**（移动端兼容）：
| 资产 | 三角面 | 材质数 | LOD |
|------|--------|--------|-----|
| 主角 | 25K | 4 | LOD0/1/2 |
| 普通 NPC | 12K | 2 | LOD0/1 |
| 普通敌人 | 15K | 3 | LOD0/1 |
| 精英/BOSS | 40K | 5 | LOD0/1 |
| 武器 | 8K | 2 | LOD0/1 |

**UV 规范**：
- 4096 贴图（角色）/ 2048（场景）
- 统一 texel density，保证视觉一致性
- UV 岛间距 ≥ 4px，避免光照渗漏

**PBR 材质**：
- BaseColor / Normal / Roughness / Metallic / AO
- 材质球统一命名规范，材质实例可复用

## 三、模型优化

- 顶点合并：静态场景合批，动态角色合批分组
- 骨骼：主角 75 根骨骼，普通 NPC ≤ 50 根
- 材质实例化：共享材质降低 Draw Call
- 压缩：顶点/法线/UV 精度压缩，减少内存占用

## 四、验证指标

- 同屏角色模型加载 < 500ms
- 角色模型内存 < 50MB（含贴图）
- 材质数 ≤ 4（主角），Draw Call 可控
