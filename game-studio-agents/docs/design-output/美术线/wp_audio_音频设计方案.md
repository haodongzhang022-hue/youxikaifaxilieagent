# wp_audio · 音频设计方案

- **工作包**：wp_audio 剧情/战斗配乐音效
- **部门**：美术线
- **主责角色**：audio_designer（音频设计师·氛围向）
- **模块**：narrative
- **产出物类型**：audio_asset（音频设计文档）

## 一、音频风格定位

**核心风格**：星际科幻 × 神秘远古，冷冽中带温润

- **音色体系**：合成器铺底（苍穹中枢）+ 打击乐（战斗）+ 管弦乐（剧情叙事）
- **动态范围**：环境音 -30~-20dB、战斗音 -10~-5dB、UI 音 -20~-15dB
- **空间感**：5.1/7.1 环绕，混响按大陆空间尺度差异化

## 二、音效清单

### 2.1 战斗音效
| 类别 | 描述 |
|------|------|
| 普攻命中 | 短促金属+空气压缩音 |
| 重击命中 | 厚重低频+碎屑音 |
| 闪避 | 气流破空+快速位移 |

| 大招 | 蓄力→爆发二段式 |

### 2.2 环境音效
| 大陆 | 声音特征 |
|------|---------|
| 苍穹中枢 | 空灵铺底 + 星核脉动 |

| 熔岩裂谷 | 熔岩翻滚 + 机械运转 |
| 冰封雪原 | 冰晶碎裂 + 寒风呼啸 |
| 云雾之岛 | 鸟鸣 + 云海流动 |

### 2.3 UI 音效
- 点击：短促高频「嗒」音
- 悬停：轻微上滑音
- 成功：上行双音（星核能量感）
- 错误：低频下探音

## 三、背景音乐

### 3.1 场景 BGM
| 场景 | 风格 | BPM | 情绪 |
|------|------|-----|------|
| 主菜单 | 史诗空灵 | 70 | 探索神秘 |
| 探索区 | 轻盈 | 90 | 好奇冒险 |
| 普通战斗 | 紧张刺激 | 120 | 战斗张力 |
| Boss 战 | 史诗压迫 | 140 | 高潮对决 |
| 剧情演出 | 叙事管弦 | 80 | 情绪共鸣 |

### 3.2 音乐适配
- 战斗音乐强度随敌人数量/生命值动态调整（Intensity 0-10）
- 场景切换交叉淡化 1.5s
- 主旋律各章节以不同配器变奏

## 四、配音设计

- **语言**：中文普通话（可扩展英/日）
- **角色方向**：主角（成长型中性音）、伊芙（低沉沉稳女声）、卡恩（豪迈男声）、虚空领主（低哑压迫感）
- **录音规格**：48kHz/24bit
- **语音系统**：VoiceOver + DialogueUI 字幕同步（≤50ms）

## 五、性能与整合

- 音频格式：WAV 源 + OGG 发布（128kbps）
- 常驻内存：UI/核心战斗音 ≤32MB
- 同时播放：≤16 音源 + 2 组混响
- 总内存 ≤64MB，无爆音/卡顿
