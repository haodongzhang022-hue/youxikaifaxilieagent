## 一、UI/UX 核心设计原则

**核心命题**：交互复杂度匹配引擎层级，同一产品在四引擎下 UI 深度不同。

| 维度 | L0 纯网页 | L1 Cocos | L2 Unity | L3 UE |
|------|----------|----------|----------|-------|
| 界面形态 | 网页SPA | 移动端H5/小程序 | 原生App | PC/Console 全屏 |
| 操作方式 | 鼠标/触摸 | 触摸为主 | 触摸+键鼠 | 键鼠+手柄 |
| 信息密度 | 低（一屏一主操作） | 中（功能分Tab） | 高（多面板可切换） | 极高（HUD+菜单+日志） |
| 导航深度 | ≤2级 | ≤3级 | ≤4级 | 无限（模块化） |

## 三、核心界面流程（对齐 wp_gameplay 核心循环）

### 3.1 L0 纯网页

```
首页 → 关卡选择 → 战斗 → 结算 → 分享回流
```

- 单屏操作，无复杂菜单
- 进度条式导航 + 底部单一 CTA
- 分享回流是唯一社交入口

### 3.2 L1 Cocos

```
登录 → 主界面 → 关卡推进 → 资源收集 → 角色成长 → 分享回流
```

- 底部 Tab 导航（主页/关卡/角色/商城）
- 章节式关卡列表 + 星级评价
- 付费引导（首次充值弹窗 + 限时优惠）

### 3.3 L2 Unity

```
登录 → 主城 → 功能大厅（战斗/养成/公会/商城） → 各功能子界面
```

- 侧边栏 + 主界面多功能切换
- 主城 3D 场景 + UI 叠加层
- 商城多分类 + 月卡/礼包入口

### 3.4 L3 UE

```
启动 → 主菜单 → 加载 → 开放世界 → HUD → 菜单/地图/背包/任务
```

- 全屏 HUD（血条/技能栏/小地图/任务追踪）
- 快捷键 + 手柄映射（按 B 打开背包等）
- 动态菜单（打开菜单时世界暂停或减速）

## 四、视觉一致性规范

### 4.1 配色体系（对齐 art_director 风格）

| 用途 | 色值 | 应用场景 |
|------|------|---------|
| 主色调 | #1E3A5F 冷蓝 | 背景/主面板 |
| 辅色调 | #D4A94E 暖金 | CTA/高亮/星核能量 |
| 警示色 | #7B2D8B 暗紫 | 虚空侵蚀/危险提示 |
| 成功色 | #2E8B57 翠绿 | 成功反馈 |
| 文本色 | #E8E8E8 亮白 | 主要文本 |
| 次级文本 | #8A8A8A 灰 | 辅助文本 |

### 4.2 字体体系

| 引擎层级 | 字体策略 | 字号范围 |
|---------|---------|---------|
| L0 | 系统字体（无内嵌） | 14~24px |
| L1 | 内嵌2款（中文+数字） | 16~32px |
| L2 | 字体分级（标题/正文/注释） | 14~48px |
| L3 | 自定义字体全套 + 多语言 | 12~72px |

### 4.3 组件库规范

**统一组件库（跨引擎）**：
- Button（主/次/禁用/危险 4 态）
- Panel（主/弹窗/侧边 3 类型）
- ProgressBar（线性/圆形/分段）
- Dialog（确认/警告/成功）
- Toast（顶部/底部/居中）
- InputField（单行/多行/密码）

## 五、UI 渲染管线（tech_artist · 技术美术接入）

### 5.1 四引擎 UI 渲染方案

| 引擎 | UI框架 | 渲染方式 |
|------|--------|---------|
| L0 React | DOM + CSS | 浏览器渲染 |
| L1 Cocos | Cocos UI | Canvas + 图集合批 |
| L2 Unity | UGUI | Canvas + Batched |
| L3 UE | UMG | Slate + SlateBrush |

### 5.2 UI 性能预算

| 指标 | L0 | L1 | L2 | L3 |
|------|:--:|:--:|:--:|:--:|
| UI DrawCall | ≤10 | ≤20 | ≤50 | ≤100 |
| UI 纹理内存 | ≤5MB | ≤20MB | ≤50MB | ≤200MB |
| UI 更新频率 | 事件驱动 | 事件驱动 | 30fps刷新 | 60fps刷新 |

### 5.3 UI 绑定规范

```
UI 组件 ← UI 绑定层 ← 游戏数据层
```

- 数据变化 → 事件驱动 UI 更新（避免轮询）
- UI 与逻辑解耦（UI 不直接操作数据）
- 四引擎统一数据绑定协议
