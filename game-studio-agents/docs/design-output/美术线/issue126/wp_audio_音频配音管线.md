## 一、音频管线总纲

**核心原则**：音频沉浸度匹配引擎层级与叙事深度，L3 UE 达到电影级音频，L0 保持极简。

| 维度 | L0 纯网页 | L1 Cocos | L2 Unity | L3 UE |
|------|----------|----------|----------|-------|
| 音频形态 | Web Audio | 移动端音频 | 原生App音频 | PC/Console 多声道 |
| 音效量 | 基础UI音效 | 战斗+环境+UI | 完整音效+角色语音 | 全动态+空间音频 |
| BGM层 | 单轨循环 | 双轨（战斗/场景切换） | 多轨自适应 | 全动态音乐系统 |
| 配音 | 无 | 关键角色 | 全角色中英双语 | 全角色+剧情演出 |
| 空间音频 | 无 | 2D定位 | 3D定位 | 完整空间音频+HRTF |

## 二、四引擎层级音频适配矩阵

### 2.1 音效（SFX）设计

| 音效类别 | L0 | L1 | L2 | L3 |
|---------|:--:|:--:|:--:|:--:|
| UI点击 | ✅ | ✅ | ✅ | ✅ |
| 战斗音效 | 简化 | 基础 | 完整（挥砍/命中/技能） | 物理反馈+命中分层 |
| 环境音效 | — | 背景环境 | 区域环境（风声/水声） | 全动态环境（天气/时间） |
| 角色语音 | — | 关键角色简短 | 全角色战斗语音 | 全角色+剧情语音 |
| 世界音效 | — | — | 事件音效（开箱/任务） | 动态事件音效 |

**L0 简化设计**：
- 仅保留 UI 反馈 + 关键战斗音效（≤10 个音效文件）
- 使用 Web Audio API 程序化生成，避免加载大音频资源

**L1 移动端设计**：
- 音效文件优化（Ogg Vorbis 格式，单文件 ≤ 500KB）
- 双轨 BGM（战斗/场景自动切换）
- 关键角色战斗语音（≤5 句/角色）

**L2 商业化设计**：
- 完整音效库（含技能特效、命中反馈、环境切换）
- 全角色战斗语音（攻击/受击/技能/胜利）
- 剧情过场配音（关键剧情全配音）

**L3 3A设计**：
- 全动态音效系统（音量/混响实时调整）
- 空间音频 + HRTF（听声辨位）
- 全剧情演出配音 + 音乐剧式 BGM 编排

### 2.2 BGM（背景音乐）体系

| 场景 | L0 | L1 | L2 | L3 |
|------|:--:|:--:|:--:|:--:|
| 主界面 | 单曲循环 | 单曲+动态切换 | 主题曲+UI变奏 | 完整主题+动态混音 |
| 战斗 | 简单节奏 | 战斗BGM | 战斗分层（轻/中/重） | 动态战斗音乐系统 |
| 剧情 | — | 剧情过渡 | 过场音乐 | 电影级配乐 |
| 环境 | — | 区域环境 | 区域主题 | 全区域动态音乐 |

**BGM 情绪引导**（对齐 wp_narrative 世界观）：
- **苍穹中枢**：空灵、宁静的星轨感（弦乐+电子氛围）
- **氏族区**：每个氏族独立音乐主题（七族各异）
- **虚空侵蚀区**：低沉压迫、失真感（低频+噪声层）
- **遗迹探索区**：神秘探索感（古乐+电子混音）

## 三、音频资源格式与引擎映射

### 3.1 中立源格式

```
音频源文件（WAV 44.1kHz/48kHz）→ 各引擎转换
```

| 引擎层级 | 最终格式 | 采样率 | 压缩 |
|---------|---------|:------:|------|
| L0 | OGG Vorbis | 44.1kHz | 高质量压缩 |
| L1 | OGG Vorbis | 44.1kHz | 高质量压缩 |
| L2 | WAV / OGG | 44.1kHz | 无损/高质量 |
| L3 | WAV 多声道 | 48kHz | 无损 |

### 3.2 引擎音频系统映射

| 引擎 | 音频系统 | 特性 |
|------|---------|------|
| L0 React | Web Audio API | 程序化音频，无需外部文件 |
| L1 Cocos | AudioClip + AudioSource | 移动端优化，支持循环/淡入淡出 |
| L2 Unity | AudioSource + AudioMixer | 完整3D音频，混音组，空间定位 |
| L3 UE | MetaSound + AudioCue | 全动态音频，程序化合成，环境系统 |
