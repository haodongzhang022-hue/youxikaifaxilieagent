## 一、世界观视觉方向

**风格定位**：硬核幻想 + 科技遗迹融合
- 视觉基调：厚重质感、冷暖对比、光影层次
- 色彩体系：主色调（星蓝/暗金），强调色（虚空紫）
- 氛围塑造：失落文明遗迹的沧桑感 + 星械科技的冷冽感

**七块浮空大陆**：
| 大陆 | 视觉主题 | 色彩基调 |
|------|---------|---------|
| 苍穹中枢 | 古代能源核心 | 星蓝+银白 |
| 星陨平原 | 战痕遗迹 | 土黄+暗红 |
| 永夜森林 | 幽暗森林 | 深绿+墨紫 |
| 熔岩裂谷 | 火山地脉 | 暗红+橙金 |
| 冰封雪原 | 极寒之地 | 冰蓝+纯白 |
| 云雾之岛 | 浮空岛屿 | 天蓝+云白 |
| 虚空之海 | 侵蚀之地 | 紫黑+深邃 |

## 四、美术品质基准

- **原画精度**：2048×2048 概念图，细节层级 LOD0/1/2
- **角色卡**：立绘 + 三视图 + 表情差分（12 种）
- **风格统一**：所有角色/怪物/场景保持统一的星械+虚空体系
