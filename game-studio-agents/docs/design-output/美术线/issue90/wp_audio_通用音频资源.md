- **工作包**：wp_audio 通用音频资源
- **部门**：美术线

- **模块**：audio / cross-platform-audio

- **场景**：Issue #90「跨平台架构增强」——需在 Web/Cocos/Unity/UE 四引擎间建立统一的音频资源体系

---

## 一、通用音频设计目标

### 1.1 核心目标

> 同一份音频资产在四引擎中**保持一致的听觉体验**，最大化音频复用，降低多引擎音频适配成本。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **中立格式优先** | 音频源以 WAV（无损）存储，按引擎/平台目标压缩分发 |
| **响度统一** | 全局响度标准化（LUFS），跨端播放响度一致 |
| **分类管理** | 音频按类型（BGM/SFX/UI/VO）分级管理，加载策略差异化 |
| **动态混音** | 统一的 Ducking/侧链/空间参数，各引擎混音器配置一致 |
| **程序化生成** | 程序化生成音频（环境音/机械音）基于参数输出，支持跨端复用 |

## 三、音频分类与加载策略

### 3.1 音频分类体系

```
assets/source/audio/
├── bgm/                    # 背景音乐
│   ├── world/              # 场景 BGM（7 座浮空大陆）
│   ├── combat/             # 战斗 BGM
│   ├── narrative/          # 剧情/过场 BGM
│   └── menu/               # 菜单/界面 BGM
├── sfx/                    # 音效
│   ├── combat/             # 战斗音效（命中/闪避/技能/大招）
│   ├── environment/        # 环境音效（大陆/天气/遗迹）
│   ├── interaction/        # 交互音效（物品/机关/传送）
│   └── ui/                 # UI 音效（点击/悬停/弹窗/成就）
├── vo/                     # 语音
│   ├── dialogue/           # 对话语音
│   ├── narration/          # 旁白
│   └── unit_voice/         # 角色语音
└── procedural/             # 程序化生成参数
    ├── ambient_params.json  # 环境音生成参数
    └── machine_params.json  # 机械音生成参数
```

### 3.2 加载策略

| 音频类型 | 加载方式 | Web | Cocos | Unity | UE |
|---------|---------|-----|-------|-------|-----|
| UI 音效 | 常驻内存 | ✅ 预加载 | ✅ 预加载 | ✅ 预加载 | ✅ 预加载 |
| 核心 SFX | 常驻内存 | 按需加载 | 按需加载 | 预加载 | 预加载 |
| 场景 BGM | 按场景加载 | 按场景 | 按场景 | 按场景 + 缓存 | 按场景 + 缓存 |
| 战斗 BGM | 切换加载 | 按需 | 按需 | 按需 | 按需 |
| VO | 按需流式 | 按需 | 按需 | 流式 | 流式 |
| 程序化 | 参数→合成 | 生成 | 生成 | 生成 | 生成 |

## 四、混音系统设计

### 4.1 全局音频总线架构

```
Master Bus
├── BGM Bus（-10dB 基准）
├── SFX Bus（-6dB 基准）
├── UI Bus（-15dB 基准）
├── VO Bus（-8dB 基准）
└── Ambient Bus（-20dB 基准）
```

### 4.2 各引擎混音总线对照

| 总线 | Web/WebAudio | Cocos | Unity (Mixer) | UE (AudioMixer) |
|------|-------------|-------|---------------|----------------|
| Master | GainNode | Audio Manager | Master Group | Master |
| BGM | GainNode | Music | Music Group | BGM Group |
| SFX | GainNode | Effect | SFX Group | SFX Group |
| UI | GainNode | UI | UI Group | UI Group |
| VO | GainNode | Voice | VO Group | VO Group |

### 4.3 动态混音规则（全端统一）

| 规则 | 参数 | 说明 |
|------|------|------|
| Ducking（BGM 压低） | BGM -6dB when VO 播放 | 对话时 BGM 自动压低 |
| Sidechain | SFX 攻击时 BGM 短时压低 | 提升打击感 |
| Priority | VO > SFX > Ambient > BGM | 音频优先级 |
| Loudness | 全端 -14 LUFS | 响度标准统一 |

## 五、程序化音频生成

### 5.1 程序化音频参数化

```json
// 程序化环境音生成参数
{
  "type": "wind",
  "seed": 42,
  "params": {
    "intensity": 0.7,          // 风速
    "direction": "NW",         // 风向
    "freq_range": [20, 800],   // 频率范围
    "resonance": 0.3,          // 共鸣度
    "layer_count": 3,          // 混合层数
    "mix": {
      "noise": 0.6,            // 噪声占比
      "tone": 0.4              // 纯音占比
    }
  }
}
```

### 5.2 程序化生成工作流

```
seed + 参数 → 音频合成引擎（引擎无关） → 输出中立音频数据
    │
    ├── Web:  WebAudio API 实时合成
    ├── Cocos: 预生成 WAV/OGG 资源
    ├── Unity: 运行时合成 / 预生成 AudioClip
    └── UE:    MetaSounds 节点参数化
```

### 5.3 程序化生成优势

- **同一种子 → 相同声音**：跨引擎可复现
- **参数化调参**：无需重新录音，改参数即可迭代
- **动态环境音**：根据场景状态实时调整音频参数
- **减少资源体积**：程序化音频不占大量存储

## 六、音频品质基准

### 6.1 响度标准

| 音频类型 | 目标响度 | 峰值限制 | 说明 |
|---------|---------|---------|------|
| BGM | -14 LUFS | -1 dBTP | 全端统一 |
| SFX | -12 LUFS | -1 dBTP | 战斗感增强 |
| UI | -18 LUFS | -3 dBTP | 不干扰 |
| VO | -14 LUFS | -1 dBTP | 对话清晰 |
| 环境 | -22 LUFS | -6 dBTP | 氛围衬托 |

### 6.2 音频延迟预算

| 引擎 | 触发到发声延迟 | 目标 |
|------|-------------|------|
| Web | ≤50ms | UI 点击即时反馈 |
| Cocos | ≤30ms | UI 点击即时反馈 |
| Unity | ≤20ms | 战斗音效低延迟 |
| UE | ≤15ms | 战斗音效低延迟 |

### 6.3 跨端一致性校验

| 校验项 | 方法 | 容差 |
|--------|------|------|
| 响度 | LUFS 测量 | ≤1 LUFS 偏差 |
| 延迟 | 播放延迟测量 | ≤15ms 偏差 |
| 音质 | 频谱对比 | 频谱包络相似度 ≥90% |
| 程序化一致性 | 同 seed 对比 | hash 一致 |

## 八、音频与美术风格的一致性

### 8.1 跨平台风格统一

「赛博星核 × 失落文明」音频风格在四端保持一致：

| 维度 | 统一标准 | 实现方式 |
|------|---------|---------|
| 音色体系 | 合成器 + 打击乐 + 管弦乐 | 全端统一音频源 |
| 色彩 | 冷冽 + 温润 | 混响/均衡参数统一 |
| 空间感 | 5.1/7.1 环绕 | 各引擎空间音频方案 |
| 节奏 | 战斗 BPM 统一 | 同一音频源跨端 |

### 8.2 各引擎空间音频实现

| 引擎 | 空间音频方案 | 实现 |
|------|-----------|------|
| Web | WebAudio PannerNode | HRTF 耳机空间化 |
| Cocos | 引擎内置 3D Audio | 位置 + 衰减 |
| Unity | SpatialBlend + Reverb Zones | 3D 空间混响 |
| UE | MetaSounds + Ambisonics | 高级空间音频 |
