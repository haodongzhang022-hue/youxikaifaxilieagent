# wp_vfx · 战斗特效方案

- **工作包**：wp_vfx 战斗特效方案
- **部门**：美术线
- **主责角色**：vfx_artist（特效师·冲击向）
- **模块**：combat
- **产出物类型**：vfx_doc（特效设计文档）

## 一、特效风格

**核心风格**：冷冽星械 + 虚空侵蚀

**打击感特效**：
- 命中顿帧：命中瞬间 0.05s 全屏停顿
- 打击闪光：命中点白色闪帧 + 星蓝碎片飞散
- 震屏：重击 0.15s 横向震动（幅度 5px）

**技能特效**：
| 职业 | 技能 | 特效关键词 |
|------|------|-----------|
| 守望者 | 星械变形 | 粒子重组、光刃展开 |
| 星匠 | 护盾 | 能量护罩、结晶化 |
| 织雾者 | 治疗链 | 雾气流动、光点飞散 |
| 虚空猎手 | 背刺 | 残影、裂空斩 |

## 二、特效技术规格

**粒子系统**：
- 粒子预算：同屏 3000 粒子（战斗场景）
- 特效时长：≤ 2s（超时自动回收）
- LOD：远处降级（粒子数减半 / 关闭阴影）

**材质**：
- 常用效果：溶解 / 闪烁 / 扭曲 / 流光
- 后处理：Bloom / 径向模糊 / 色差（可选）

## 三、特效清单

| 特效 | 类型 | 触发点 |
|------|------|--------|
| 普攻命中 | 打击反馈 | 每次攻击命中 |
| 技能释放 | 技能演出 | 技能释放瞬间 |
| 闪避 | 移动残影 | 闪避动作 |
| 格挡 | 弹反特效 | 成功格挡 |
| 大招 | 全屏演出 | 大招释放 |
| BOSS 攻击 | 压迫特效 | BOSS 技能 |

## 四、性能验证

- 同屏特效粒子 ≤ 3000，FPS 波动 < 5%
- 特效加载 < 300ms（预加载关键特效）
- 特效内存 < 100MB（含粒子材质）
