# wp_ui_visual · 界面视觉/交互规范

- **工作包**：wp_ui_visual 界面视觉与交互规范
- **部门**：美术线
- **主责角色**：ui_ux（UI/UX设计师·体验向）+ tech_artist（技术美术·管线向）
- **模块**：gameplay
- **产出物类型**：ui_asset（UI 设计文档）

## 一、UI 视觉体系

### 1.1 设计语言
- **风格**：「赛博星核 × 失落文明」——冷蓝+暖金+暗紫三色体系
- **字体**：中文思源黑体 + 英文 Orbitron（标题装饰）
- **图标**：线面结合 + 星核能量光效点缀

### 1.2 色彩规范
| 用途 | 色值 | 说明 |
|------|------|------|
| 主色（冷蓝） | #1E3A5F | 界面背景/框架 |
| 强调色（暖金） | #D4A017 | 按钮/关键元素 |
| 警示色（虚空紫） | #6B21A8 | 危险/负面反馈 |
| 文字主色 | #E0E6F0 | 主要文字 |
| 文字辅色 | #8899AA | 辅助文字 |

## 二、核心界面设计

### 2.1 战斗 HUD
- **布局**：左下体力、右下技能（3+1）、中央怒气条、左上任务提示
- **反馈**：受击红闪 150ms、技能冷却遮罩、大招充能发光条
- **信息密度**：同时显示 ≤8 元素，关键信息始终可见

### 2.2 主界面
- **布局**：四宫格（继续旅程/星械工坊/氏族社交/设置）
- **视觉**：全屏背景 + 动态星核光效

### 2.3 背包/星械
- **布局**：左侧列表（图标+名称+品质色）、右侧详情
- **品质色**：白<绿<蓝<紫<金（对齐数值模型）

### 2.4 任务/世界观
- **任务面板**：章节任务树 + 详情
- **世界观图鉴**：氏族/角色/地点分类浏览

## 三、交互规范

- **导航**：扁平导航 + 面包屑，一级页面直达
- **反馈**：点击缩放 0.95 / 悬停高亮 / 错误震动
- **无障碍**：对比度 ≥4.5:1，触控目标 ≥44px
- **多输入**：键鼠 + 手柄 + 触屏三输入支持

## 四、组件库

- **按钮**：主（金边发光）/次（冷蓝描边）/禁用（降饱和）
- **弹窗**：磨砂玻璃 + 圆角 8px + 三键布局
- **进度条**：分段式 + 渐变填充（蓝→金）
- **图标集**：40+ SVG 功能图标

## 五、UI 实现对接（tech_artist）

- **渲染**：UI 专用着色器（发光描边/磨砂/渐变），变体 ≤8
- **图集**：Sprite Atlas 合图，单图集 ≤1024²
- **数据绑定**：GameplayCore 实时数据 + message_bus 事件驱动刷新

## 六、验收标准

- 页面可达 ≤2 次点击
- 多分辨率适配无遮挡/溢出
- 单界面 Draw Call ≤20，UI 内存 ≤64MB
- UI 动效帧率 ≥60fps
