## 三、LOD 与性能

### 3.1 LOD 方案
- LOD0：完整细节（视距 0~30m）
- LOD1：简化 50%（视距 30~80m）
- LOD2：极简 15%（视距 80m+）
- 远景：Imposter 代理（视距 >200m）

### 3.2 性能预算
| 指标 | PC 端 | 移动端 |
|------|-------|--------|
| Draw Call | ≤500 | ≤200 |
| 三角面总量 | ≤1M | ≤500K |
| 同屏物件 | ≤500 | ≤200 |
| 场景内存 | ≤256MB | ≤128MB |

## 四、场景制作流程

1. **概念设计**（concept_artist）：场景氛围图 + 布局参考
2. **白盒搭建**（modeler）：灰盒布局验证（寻路/可玩性）
3. **精细资产**（modeler）：高模制作 → 低模烘焙（Normal/Hand-painted）
4. **材质灯光**（modeler + tech_artist）：PBR 材质 + 光照方案（实时方向光 + 烘焙静态光）
5. **集成验证**（tech_artist）：性能检测 + 视觉一致性检查

## 五、验证指标

- 场景加载 < 2s（PC）/ < 4s（移动端）
- 场景切换无内存泄漏（连续切换 10 次内存增量 < 5MB）
- 视觉一致性与设计基准匹配 ≥95%
