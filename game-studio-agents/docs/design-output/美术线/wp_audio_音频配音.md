# wp_audio · 音频与配音设计

- **工作包**：wp_audio 音频与配音设计
- **部门**：美术线
- **主责角色**：audio_designer（音频设计师·氛围向）
- **模块**：audio
- **产出物类型**：audio_asset（音频设计文档）

## 一、音频风格定位（audio_style）

### 1.1 整体音色基调
- **氛围**：星际科幻 × 神秘远古，冷冽中带温润（浮空大陆的空灵感）
- **音色体系**：合成器铺底（苍穹中枢）+ 打击乐（战斗）+ 管弦乐器（剧情叙事）
- **动态范围**：环境音 -30dB~-20dB、战斗音 -10dB~-5dB、UI 音 -20dB~-15dB

### 1.2 声音设计原则
- **空间感**：环境音使用 5.1/7.1 环绕，混响模拟各大陆空间尺度（遗迹空旷 vs 洞穴密闭）
- **情绪引导**：剧情章节切换时用音色转变（从宁静→紧迫→史诗），引导玩家情绪曲线
- **反馈即时性**：战斗/UI 反馈音延迟 ≤80ms，保证「动作-声音」同步

## 二、音效清单（sfx）

### 2.1 战斗音效
| 音效类别 | 描述 | 素材建议 |
|---------|------|---------|
| 普攻命中 | 短促清脆的打击音（金属+空气压缩） | 合成金属/锤击样本 |
| 重击命中 | 厚重低频 + 碎屑音（震屏配合） | 低频鼓击+碎裂粒子音 |
| 闪避 | 气流破空 + 快速位移音 | 风速采样 + 短促合成音 |
| 弹反 | 金属碰撞清脆音（高辨识度奖励音） | 金属对击+泛音 |
| 技能释放 | 按职业区分：星匠厚重机械音/织雾者柔和水声/虚空猎手尖锐划破音 | 合成器 + 采样混合 |
| 大招 | 蓄力→爆发二段式（蓄力渐强+爆发重击） | 低频铺底+高频打击 |

### 2.2 环境音效
- **苍穹中枢**：空灵持续铺底（低频嗡鸣）+ 星核能量脉动（间歇光效音）
- **星烬平原**：风声 + 远处崩塌回响 + 残骸金属吱呀
- **雾岚群岛**：水声 + 鸟类啼鸣 + 云雾流动感
- **熔铁裂谷**：熔岩翻滚 + 机械运转声 + 热浪扭曲感
- **虚空边界**：压抑低频 + 异形嘶鸣 + 腐蚀滴落声

### 2.3 UI 音效
- **点击**：短促清脆的「嗒」音（高频 2kHz + 快速衰减 100ms）
- **悬停**：轻微上滑音（高频渐变）
- **成功反馈**：上行双音（星核能量感）
- **错误反馈**：低频下探音（拒绝感）

## 三、背景音乐（bgm）

### 3.1 主题音乐结构
| 场景 | 风格 | 速度 BPM | 情绪 |
|------|------|---------|------|
| 主菜单 | 史诗空灵 | 70 | 探索神秘感 |
| 探索区 | 轻盈探索 | 90 | 好奇/冒险 |
| 战斗区（普通） | 紧张刺激 | 120 | 战斗张力 |
| 战斗区（Boss） | 史诗压迫 | 140 | 高潮对决 |
| 剧情演出 | 叙事管弦 | 80 | 情绪共鸣 |
| 结算/胜利 | 轻松凯旋 | 100 | 成就感 |

### 3.2 音乐动态适配
- **自适应系统**：战斗音乐强度随敌人数量/生命值动态调整（Intensity 0-10）
- **无缝过渡**：场景切换 BGM 交叉淡化 1.5s，章节切换音乐主题变奏
- **主题贯穿**：主旋律在不同章节以不同配器变奏，强化世界统一感

## 四、配音设计（voiceover）

### 4.1 角色配音
- **语言**：中文配音（普通话），可选英/日语音包
- **配音方向**：主角（成长型中性音）、导师伊芙（低沉沉稳女声）、卡恩（浑厚豪迈男声）、虚空领主（低哑压迫感男声）
- **录音规格**：48kHz/24bit，干音+环境混响分层

### 4.2 语音系统对接
- **触发机制**：剧情对话/任务接取/战斗台词/系统提示四类触发
- **字幕同步**：VoiceOver 与 DialogueUI 字幕对齐（延迟 ≤50ms）
- **音量控制**：语音默认 -6dB（突出于背景音效），可单独调节

## 五、音频性能与整合

### 5.1 资源规格
- 音频格式：WAV（无损源）+ OGG（发布压缩 128kbps）
- 加载方式：常驻内存（UI/核心战斗音 ≤32MB）+ 流式加载（BGM/环境音）
- 同时播放上限：≤16 音源（非混响）+ 2 组混响总线

### 5.2 性能目标
- 音频内存占用 ≤64MB
- 动态负载：单场景环境音同时 ≤8 个音源
- 无卡顿/爆音（音频缓冲 ≥128ms，异步加载避免主线程阻塞）
