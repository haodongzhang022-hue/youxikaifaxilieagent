## 一、多端数据埋点方案设计

针对四级引擎流水线（React→Cocos→Unity→UE），建立**统一埋点协议 + 分端采集策略**。

### 1.1 统一埋点协议（跨端一致）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| event_id | string | 事件唯一标识 | `battle_start` |
| player_id | string | 玩家 ID（服务端统一账本） | `u_10001` |
| platform | enum | 平台标识 web/cocos/unity/ue | `web` |
| client_version | string | 客户端版本（对应 M1-M5 里程碑） | `M2_0.1.0` |
| ts | int64 | 服务端统一时间戳（ms） | `1724800000000` |
| params | map | 事件参数（与策划数值模型字段对齐） | `{"stage":3,"dps":1280}` |

**核心原则**：
- 埋点数据由**服务端权威**统一记账（对接 wp_server 服务端统一账本）；
- 四端上报同一协议，服务端侧归一化，保证跨端数据可比；
- 参数取值与策划数值模型（wp_numeric_model 定点数配置表）对齐，避免口径漂移。

### 1.2 分端埋点策略

| 引擎 | 端类型 | 埋点重点 | 采集频率 |
|------|--------|---------|---------|
| React | Web 引流端 | 分享传播链路 / 首登激活 / 注册转化 | 事件级 + 页面级 |
| Cocos | 小程序端 | 小程序启动 / 快速玩法留存 / 分享回流 | 事件级 + 轻量采样 |
| Unity | 完整 App 端 | 完整玩法深度 / 数值消费 / 长线留存 | 全量事件 |
| UE | 高保真端 | 高质量效果体验 / 迁移成本验证 / 付费深度 | 全量事件 + 性能采样 |

**跨端转化漏斗**（运营关键指标）：
```
Web 曝光 → 分享 → 小程序激活 → 注册 → 安装 Unity → 付费 → 长线留存
  ↓         ↓        ↓          ↓        ↓         ↓         ↓
 曝光率   分享率    激活率     注册率    安装率    付费率    留存率
```

### 1.3 数据采集与链路

```
各端 SDK ─→ 统一网关（wp_server）──→ Kafka ─→ 数仓(ETL) ─→ 分析看板
   │                │                                        │
 事件协议          服务端权威                                运营洞察
（1.1 协议）      （归一化/去重）                          （BI/报表/预警）
```

## 二、运营洞察与用户增长策略

### 2.1 多端留存优化

| 阶段 | 优化目标 | 策略 |
|------|---------|------|
| 首日激活 | D1 ≥ 40% | 引导式新手教程 + 分享奖励倒计时 |
| 7 日留存 | D7 ≥ 18% | 每日任务 + 社交互助 + 阶段性活动 |
| 30 日留存 | D30 ≥ 10% | 赛季制内容 + 长线养成 + 版本节奏（对齐 M1-M5） |

### 2.2 商业化洞察（消费多端模型）

- 消费策划 wp_numeric_model 商业化结构（金币/星核/蚀潮石）；
- 四端差异化投放：Web/Cocos 侧重轻量 IAA（广告）+ 分享激励，Unity/UE 侧重深度 IAP（内购养成）；
- **关键告警**：IAP 占比 > 90%（见生态位诊断），需主动补 IAA 平衡商业化结构。

### 2.3 用户增长飞轮

```
多端引流（Web/Cocos 轻量）→ 低成本获客 → 内容深度（Unity/UE）→ 高质量留存 → 口碑传播 → 回流 Web 分享
```

## 三、市场生态位诊断（wp_data_ops · data_analyst 落地）

> 消费策划线 wp_numeric_model 市场预演输入（base_quality=68.0 / arpu=2.8 / mass_player_base=300000），
> 经 market_simulator + data_ops_diagnosis 跑出纳什均衡结果。

### 3.1 生态位健康度诊断

| 指标 | 数值 | 健康度 |
|------|------|--------|
| DAU | 47214 | 达标（>5000） |
| 30 日留存 | 10.73% | 达标（≥8%） |
| 口碑（reputation） | 4.65/10 | 良好（≥3.5） |
| ROI | 23.92 | 优秀（>1.0） |
| **商业化结构** | IAP 占比 99.6% | ⚠️ 过度依赖内购，抗风险弱 |

**生态位判定**：稳健/可优化（健康分 4/5）
- ✅ DAU/留存/口碑/ROI 全部达标；
- ⚠️ 商业化过度依赖 IAP（99.6%），广告(IAA)占比极低，抗风险弱。

### 3.2 敏感性分析（沿 iap_depth 轴）

| IAP 深度 | 总营收 | ROI | 结论 |
|---------|--------|-----|------|
| 0.3 | 108 万 | 9.02 | 稳健基线 |
| 0.5 | 179 万 | 14.98 | 中位 |
| 0.7 | 251 万 | 20.94 | 高成长 |
| 0.9 | 322 万 | 26.90 | 峰值 |

**结论**：敏感度中等（营收 CV=0.371），IAP 深度上探可显著拉高营收，但需注意商业化结构失衡风险。

### 3.3 发布建议

**判定**：✅ **GO** — 可正常发布：生态位健康，具备发布条件。

- **发布时机**：优先发布（高 ROI，抢占生态位）；
- **护栏**：参数敏感性中等，发布时设置 IAP 下限护栏 + 动态监控商业化结构。
