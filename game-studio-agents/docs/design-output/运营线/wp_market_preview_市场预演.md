# wp_market_preview · 市场预演与生态位诊断

- **工作包**：wp_market_preview 市场预演与生态位诊断
- **部门**：运营线
- **主责角色**：data_analyst（数据分析师·策略向）
- **模块**：data_ops
- **产出物类型**：ops_report（运营报告）

## 一、市场预演输入

消费上游产出构建市场预演标准化输入：

| 输入维度 | 来源 | 数值 |
|---------|------|------|
| 美术品质 | 美术线 art_direction | 72.0 |
| 基础品质 | 策划线 numeric_model | 65.0 |
| ARPU | 策划线 numeric_model | 2.5 |
| eCPM | 策划线 numeric_model | 6.0 |
| 广告展示 | 策划线 numeric_model | 8次/日 |
| 渠道分成 | 策划线 numeric_model | 30% |

## 二、市场预演结果

**纳什均衡**：
- 玩家圈（大众/核心/付费/试玩）策略收敛
- 外部市场（发行/广告/渠道）竞争平衡
- 美术品质维度生效（玩家偏好驱动）

**生态位诊断**：
- 大众玩家基数：20 万
- 付费转化率：3-5%（预期）
- 广告变现收益：达预期
- 市场竞争力：中上（vs 竞品）

## 三、运营建议

- 首月目标：DAU 5 万，次日留存 40%+
- 付费设计：皮肤/月卡/通行证三级
- 广告位：激励视频 + 插屏（平衡体验）

## 四、验证指标

- 市场预演模拟 10 轮收敛
- 敏感度分析覆盖 5 个关键参数
- 运营建议可落地（有数据支撑）
