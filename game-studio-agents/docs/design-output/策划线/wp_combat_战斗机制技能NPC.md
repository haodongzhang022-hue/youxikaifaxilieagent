## 一、战斗机制框架（combat_system）

**核心循环**：定位→接敌→输出→规避→追击/撤离

**机制设计**：
- **实时动作 + 技能判定**：普攻连段、重击、闪避（无敌帧）、格挡（弹反）
- **资源系统**：体力（行动消耗）+ 星核能量（技能资源）+ 怒气（大招）
- **操作反馈**：命中停顿、受击反馈、震屏、打击特效，保证「手感」爽快

**手感目标**：
- 攻击前摇 ≤ 0.15s，后摇可取消（衔接位移/闪避）
- 闪避无敌帧 0.3s，弹反窗口 0.2s（高手向奖励）
- 连段系统：普攻 3 连 → 重击 → 派生技

## 二、技能与职业设计（skills）

| 职业 | 定位 | 核心机制 | 技能风格 |
|------|------|---------|---------|
| 守望者（主角） | 均衡输出 | 星械变形 | 远近结合 |
| 星匠 | 坦克/承伤 | 护盾/嘲讽 | 大开大合 |
| 织雾者 | 治疗/辅助 | 治疗链/增益 | 柔性支援 |
| 虚空猎手 | 刺客/爆发 | 隐身/背刺 | 高速连击 |

**技能数值锚点**：
- 单体技能 DPS ≈ 1.0 基准；范围技能降单体伤害换取覆盖
- 控制技能时长 ≤ 2s，目标减益存在递减机制
- 大招充能：普通战斗 60~90s 攒满，高风险场景加速充能

## 三、NPC AI 行为设计（npc_ai）

**行为模式**：
- 普通怪：巡逻→索敌→攻击→追击/回归
- 精英怪：技能预判→爆发→虚弱窗口（可反打）
- BOSS：多阶段 AI（每阶段切换行为树 + 技能组）

**难度自适应**：
- 根据玩家 DPS/生存时长动态微调攻击频率与技能释放，保证战斗体验张力
- 死亡重试后降低弹反难度（惩罚递减），避免挫败

## 四、战斗数值平衡验证（balance_verify）

- 各职业理论 DPS 差异 ≤ 10%，通过数值模型校验
- 战斗时长锚定：普通战 30~60s，精英战 60~120s，BOSS 战 3~5 分钟
- 随等级成长，战斗节奏保持「前松后紧」，难度曲线平滑
