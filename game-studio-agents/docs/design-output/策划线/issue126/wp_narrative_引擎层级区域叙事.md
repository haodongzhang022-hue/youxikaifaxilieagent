## 一、世界观分层设定

**核心主题**：「星穹守望者」——失落文明遗迹中对抗虚空侵蚀。

世界观在四层引擎下统一基础设定，但叙事深度与表现方式按引擎层级分化：

| 引擎层级 | 叙事深度 | 表现方式 | 文本量 |
|---------|---------|---------|--------|
| L0 纯网页 | 极简背景（一句话世界观） | 文字 + 简单图标 | 每关 ≤ 50 字 |
| L1 Cocos | 基础剧情线（章节制） | 文字对话 + 立绘 | 每章 500~1000 字 |
| L2 Unity | 完整主线 + 支线 + 角色弧光 | 2D/3D 对话演出 + 过场 | 每章 2000~5000 字 |
| L3 UE | 沉浸叙事 + 全区域世界观 | 全 3D 过场 + 环境叙事 | 全文本 10万+ 字 |

## 二、分区域叙事构建

**世界观核心区域**（跨引擎统一）：
1. **苍穹中枢**：游戏初始区域，新手引导 + 世界观初探
2. **浮空大陆·七大氏族区**：每氏族独立文化信仰与任务线
3. **虚空侵蚀区**：主线冲突区域，BOSS 战与高难度内容
4. **遗迹探索区**：开放探索 + 隐藏剧情（L3 专用）

**区域 × 引擎层级适配**：

| 区域 | L0 | L1 | L2 | L3 |
|------|----|----|----|----|
| 苍穹中枢 | 仅文字 | 简单立绘对话 | 2D/3D 对话 | 全 3D 沉浸引导 |
| 氏族区 | 不引入 | 每氏族 1~2 个任务 | 每氏族 5~10 任务+支线 | 每氏族完整文化任务链 |
| 虚空侵蚀区 | 最终 1 关 | 3~5 章主线 | 10+ 任务+BOSS 战 | 开放区域+动态事件 |
| 遗迹探索区 | — | — | 隐藏任务 | 全开放+解密+剧情演出 |

## 三、主线剧情按引擎层级展开

**L0 纯网页**：
- 一句话世界观：守护星穹，抵御虚空
- 单线推进：5~10 关，每关结尾文字交代剧情
- 无分支选择，无角色系统

**L1 Cocos**：
- 三章主线：觉醒 → 试炼 → 首次对抗
- 每章含「引导-推进-高潮-收束」四段式
- 2~3 个 NPC 角色，对话推动剧情
- 结尾彩蛋暗示后续章节

**L2 Unity**：
- 五章完整主线
- 完整角色弧光（主角成长线 + 2~3 个关键 NPC）
- 每章含支线任务 + 主线节点 + BOSS 战
- 结局分支（2~3 个关键抉择点）

**L3 UE**：
- 开放大世界主线 + 全区域支线
- 七大氏族完整文化背景与独立任务链
- 动态叙事（区域进度影响世界状态）
- 多结局 + 隐藏剧情 + 收集品叙事

## 五、任务文案分层设计

**任务类型 × 引擎层级**：

| 任务类型 | L0 | L1 | L2 | L3 |
|---------|----|----|----|----|
| 主线任务 | 1 条 | 1 条 | 1 条（五章） | 1 条（全区域） |
| 支线任务 | 无 | 2~3 条 | 每章 3~5 条 | 每区域 5~10 条 |
| 日常任务 | 无 | 简单 3 个 | 5~10 个 | 10~20 个（动态） |
| 成就任务 | 无 | 5 个 | 20 个 | 50+（隐藏） |

**文案风格**：
- L0：一句话交代目标，快速进入游戏
- L1：简洁对话式，每任务 2~3 轮对话
- L2：完整对话树，重情感共鸣
- L3：沉浸式环境叙事 + 对话 + 剧情演出

## 六、叙事与引擎层级对齐检查

- [ ] L0 文本量是否 ≤ 50 字/关？
- [ ] L1 是否只有基础剧情线，未引入完整角色弧光？
- [ ] L2 是否引入完整主线 + 支线 + 角色成长？
- [ ] L3 是否实现全区域动态叙事 + 多结局？
- [ ] 是否把「表现层演出」与「叙事逻辑」分离？
