## 一、四层引擎数值适配总纲

**核心原则**：数值复杂度匹配引擎层级，同一游戏世界观在不同引擎层级下的数值纵深不同。

| 数值维度 | L0 纯网页 | L1 Cocos | L2 Unity | L3 UE |
|---------|----------|----------|----------|-------|
| 货币体系 | 单一货币 | 硬/软双货币 | 多货币+商城 | 多货币+跨服交易 |
| 成长曲线 | 线性快感 | 前快后缓 | 阶段化成长 | 深度非线性养成 |
| 难度曲线 | 平缓 | 梯度递进 | 波浪式进阶 | 开放世界动态难度 |
| 经济循环 | 产出即消耗 | 产出-消耗闭环 | 防膨胀+赛季重置 | 复杂经济+跨服平衡 |
| 数值精度 | 整数 | 整数+定点 | 定点(1/1000) | 高精度 C++ 浮点 |

## 二、经济系统模型（economy）

**L0 纯网页**：
- 单一货币「金币」：通关/分享获得，用于解锁下一关卡
- 循环：通关 → 金币 → 解锁 → 通关，无复杂消耗
- 数值目标：单局收入 ≈ 解锁成本 × 0.8，3~5 局可解锁下一关

**L1 Cocos**：
- 双货币：金币（产出）+ 钻石（付费）
- 金币用于升级装备、购买道具；钻石用于加速/抽卡
- 产出-消耗比：金币 0.9~1.1，钻石需付费购买（100钻 ≈ ¥6）

**L2 Unity**：
- 多货币：金币 + 钻石 + 公会币 + 赛季币
- 商城包含：直购、礼包、月卡、抽卡（保底机制）
- 经济模型：产出-消耗比值 0.85~1.15，防通胀/紧缩
- 赛季重置：赛季币赛季末归零，驱动长线活跃

**L3 UE**：
- 复杂经济：多货币 + 稀有材料 + 跨服交易税
- 玩家间交易存在手续费（5%），抑制通胀
- 数值精度用 C++ 浮点（1/10000 级），跨服一致性校验

## 三、成长曲线按引擎层级设计

**等级曲线**：

| 引擎层级 | 1~10级 | 11~30级 | 31~60级 | 60级+ |
|---------|--------|---------|---------|-------|
| L0 | 1级/关（线性快感） | — | — | — |
| L1 | 1级/2关 | 1级/4关（放缓） | — | — |
| L2 | 1级/1关（新手爽感） | 1级/2关 | 1级/4关（长线） | 以活动/赛季补 |
| L3 | 1级/任务（快速起步） | 1级/2任务 | 1级/3任务+副本 | 深度养成+转职 |

**战力曲线**：
- L0：线性增长（单维），战力 = 等级 × 10
- L1：轻指数（等级×装备加成），30 级后放缓
- L2：非线性叠加（等级+装备+技能+天赋），峰值随内容开放
- L3：深度非线性（转职+天赋树+装备词缀+家园加成），长线养成驱动

## 四、难度曲线按引擎层级设计

**关卡难度公式**：
```
L0: difficulty = base + 0.5 × level        # 平缓线性
L1: difficulty = base + 0.8 × level        # 梯度递进
L2: difficulty = base × 1.15^level         # 波浪式进阶（含起伏）
L3: difficulty = dynamic(玩家实力)          # 动态难度（开放世界）
```

**难度体验锚点**：
- L0：每关 80% 玩家可通过（休闲导向，低挫败）
- L1：普通关 75% 通过率，Boss 关 60%（引导付费/重复挑战）
- L2：主线 70% 通过率，挑战本 40%（驱动养成投入）
- L3：动态难度调整，BOSS 战失败后可降难度（惩罚递减）

## 六、跨引擎层级复用资产

1. **数值配置表资产（Excel → JSON/Binary）**：跨引擎永远保留，换引擎不丢数据
2. **纯算法资产（抽卡/ELO/难度曲线）**：跨语言保留，单元测试保留
3. **数值基准协议**：货币/结算结构化定义，跨引擎一致
