## 一、战斗机制按引擎层级分化

**核心原则**：战斗复杂度匹配引擎能力上限。

| 战斗维度 | L0 纯网页 | L1 Cocos | L2 Unity | L3 UE |
|---------|----------|----------|----------|-------|
| 战斗模式 | 数值对撞/自动 | 自动战斗+手动释放 | 即时战斗+技能连招 | 帧同步硬核实时 |
| 操作复杂度 | 1 键点击 | 2~3 键（攻击/技能/闪避） | 完整按键（移动+技能+闪避+格挡） | 复杂操作（含连招/位移/环境交互） |
| 判定方式 | 服务器数值结算 | 服务端结算+本地预测 | 客户端预测+服务端权威 | 帧同步确定性 |
| 战斗时长 | ≤ 30s | 30~60s | 60~120s | 3~5 分钟（BOSS） |

## 二、战斗核心循环分层

**L0 纯网页**：
```
点击攻击 → 数值结算 → 伤害反馈 → 击败/失败 → 重试/下一关
```

**L1 Cocos**：
```
自动战斗 → 手动释放技能（QTE 时机） → 躲避攻击（滑动） → 胜利/失败
```

**L2 Unity**：
```
定位 → 接敌 → 输出（普攻连段+技能组合） → 规避（闪避/格挡） → 追击/撤离
```

**L3 UE**：
```
探索 → 锁定/判定 → 连招/位移/环境交互 → 物理反馈 → 追击/BOSS战
```

## 三、技能体系按引擎层级配置

**技能系统框架**：

| 技能类型 | L0 | L1 | L2 | L3 |
|---------|----|----|----|----|
| 普攻连段 | — | 1 段 | 3 段 | 5 段+派生 |
| 主动技能 | 1 个 | 3 个 | 5~8 个 | 10+ 个 |
| 被动技能 | — | 2 个 | 4~6 个 | 10+ 个 |
| 大招/必杀 | — | 1 个 | 2 个 | 3+ 个 |
| 环境交互 | — | — | — | 完整 |

**技能数值锚点（跨引擎统一）**：
- 单体技能 DPS ≈ 1.0 基准
- 范围技能降单体伤害换取覆盖
- 控制技能时长 ≤ 2s，递减机制
- 大招充能：普通战斗 60~90s 攒满

## 五、NPC AI 触发器逻辑分层设计

**AI 触发器核心模块**（引擎无关，跨引擎复用）：

```
┌─ AI 状态机（巡逻/索敌/攻击/追击/回归）
├─ 行为树（精英怪技能预判/爆发/虚弱窗口）
├─ 事件触发器（血量阈值/玩家位置/时间条件触发 AI 行为切换）
├─ 难度自适应器（根据玩家 DPS 动态调整）
└─ 协议化指令（AI 决策 → 结构化指令 → 引擎执行）
```

**各引擎层级 AI 复杂度**：

| AI 维度 | L0 | L1 | L2 | L3 |
|---------|----|----|----|----|
| 状态机 | 1~2 态 | 3~4 态 | 5~8 态 | 10+ 态 |
| 行为树 | — | 简单树 | 中等树 | 完整树 |
| 触发器类型 | 血量阈值 | 血量+位置 | 血量+位置+技能CD | 完整事件触发 |
| 难度自适应 | 无 | 简单调整 | 动态调整 | 深度自适应 |
| 多阶段 BOSS | 无 | 1 阶段 | 2~3 阶段 | 5+ 阶段 |

**AI 触发器逻辑示例**：

```python
# 引擎无关 AI 触发器（L2/L3 适用）
def ai_trigger(event):
    if event.player_hp < 0.3 and event.skill_available('berserk'):
        trigger('berserk_mode')      # 玩家低血量 → Boss 进入狂暴模式
    if event.boss_hp < 0.5:
        trigger('phase_transition')  # Boss 半血 → 阶段转换
    if event.distance < 5 and event.cooldown('stomp') == 0:
        trigger('stomp_attack')      # 近距离 + 技能可用 → 踩踏攻击
    # 难度自适应：根据玩家 DPS 调整攻击频率
    adaptive_tune(dps_ratio=event.player_dps / expected_dps)
```

## 六、战斗手感目标（跨引擎统一基准）

| 手感指标 | 目标值 |
|---------|--------|
| 攻击前摇 | ≤ 0.15s |
| 攻击后摇 | 可取消（衔接位移/闪避） |
| 闪避无敌帧 | 0.3s |
| 弹反窗口 | 0.2s（高手向奖励） |
| 连段系统 | 普攻 3 连 → 重击 → 派生技 |
| 受击反馈 | 命中停顿 + 震屏 + 打击特效 |
