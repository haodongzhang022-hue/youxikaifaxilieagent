# wp_level · 关卡结构与难度曲线设计

- **工作包**：wp_level 关卡设计
- **部门**：策划线
- **主责角色**：level_designer（关卡策划·体验派）
- **模块**：level
- **产出物类型**：design_doc（关卡设计文档）

## 一、关卡结构（level_design）

**总体结构**：7 大浮空大陆 = 7 大章节，每章节含 4 个主线关卡 + 1 个 Boss 关 + 2 个支线秘境。

**地图布局**：
- 每关采用「探索区 → 战斗区 → 结算区」三段式布局
- 探索区含解谜/采集/支线触发点，控制战斗密度
- 战斗区含 1~3 波敌人 + 精英遭遇，节奏张弛有度

## 二、玩法元素（gameplay_elements）

- 环境机关：可破坏物、移动平台、能量门（需星核能量开启）
- 掩体/高低差：影响战斗走位与技能命中
- 隐藏通路：奖励探索型玩家（宝箱/稀有材料）
- 剧情触发点：与叙事节奏衔接，关键节点演出

## 三、难度曲线（difficulty_curve）

| 章节 | 敌人强度 | 战斗密度 | 解谜复杂度 | 玩家等级 |
|------|---------|---------|-----------|---------|
| 序章 | ★ | 低 | 无 | 1-5 |
| 第一章 | ★★ | 中低 | 低 | 5-12 |
| 第二章 | ★★★ | 中 | 中 | 12-20 |
| 第三章 | ★★★★ | 中高 | 中 | 20-30 |
| 第四章+ | ★★★★★ | 高 | 高 | 30+ |

**难度平滑**：
- 相邻关卡强度差 ≤ 15%，避免断崖
- 每章节末尾 Boss 为峰值，但带「教学-练习-实战」三段缓冲
- 死亡惩罚温和，重试后提供「降低弹反难度」等软保底

## 四、白盒验证（whitebox_verify）

- 寻路验证：主要通路无卡死/无死胡同
- 可玩性验证：战斗密度与跑图节奏平衡，无过长空白
- 难度验证：用数值模型模拟不同等级玩家通关时长，校准曲线

> 产出：关卡策划 level_designer 承接，产出白盒关卡与难度曲线，供程序线实现 + 测试线验收。
