- **工作包**：wp_narrative 跨平台叙事框架

- **模块**：narrative
- **产出物类型**：narrative_doc（跨平台叙事设计文档）
- **场景**：Issue #90「跨平台架构增强」——叙事内容需多端复用、轻量端适配

---

## 一、叙事架构引擎无关标准

### 1.1 叙事数据格式（引擎无关 JSON Schema）

叙事内容以**结构化数据**存储，各引擎通过适配器渲染：

```json
{
  "dialogue_id": "d_001_chap1_intro",
  "chapter": 1,
  "speaker": "伊芙",
  "text": "守望者，蚀潮即将来临...",
  "choice": [
    {"text": "我准备好了", "next": "d_002"},
    {"text": "什么是蚀潮？", "next": "d_003"}
  ],
  "trigger": {"type": "quest_complete", "quest_id": "q_001"}
}
```

### 1.2 叙事分层

```
┌─────────────────────────────────────────────┐
│  叙事逻辑层（引擎无关）                     │
│  · 对话状态机 / 分支选择                    │
│  · 任务进度判定 / 剧情触发条件              │
│  · 角色数据 / 关系系统                      │
├─────────────────────────────────────────────┤
│  叙事表现层（引擎适配器）                   │
│  · 对话 UI / 过场动画 / 演出效果            │
│  · 角色立绘 / 场景切换                      │
│  · 语音播放（可选）                         │
└─────────────────────────────────────────────┘
```

## 二、跨平台世界观框架

### 2.1 世界观核心（多端一致）

**主题**：「星穹守望者」——失落文明遗迹 + 虚空侵蚀 + 七大浮空大陆

**跨平台叙事原则**：
- 主线剧情多端一致（世界观/角色/核心事件不因平台改变）
- 轻量端提供「浓缩版」叙事（简短对话 + 关键剧情节点）
- 完整端提供「完整版」叙事（全量对话 + 过场演出 + 支线剧情）

### 2.2 端差异化叙事策略

| 平台 | 叙事深度 | 形式 | 定位 |
|------|---------|------|------|
| Web（React） | 轻量 | 文字对话 + 静态立绘 | 引流/了解世界观 |
| Cocos | 浓缩 | 简短视频 + 图文 | 快速分享传播 |
| Unity | 完整 | 全对话 + 过场动画 | 沉浸式体验 |
| UE | 高保真 | 全对话 + 电影级演出 | 高品质护城河 |

## 三、跨平台任务体系

### 3.1 任务状态机（引擎无关）

```
[未激活] → [已接取] → [进行中] → [可交付] → [已完成]
                ↑          ↓
                └── [已放弃/失败] ──┘
```

### 3.2 任务数据结构（JSON Schema）

```json
{
  "quest_id": "q_main_01",
  "title": "守望者的觉醒",
  "type": "main_story",
  "chapter": 1,
  "objectives": [
    {"id": "obj_1", "type": "talk", "target": "npc_伊芙", "desc": "与伊芙对话"},
    {"id": "obj_2", "type": "kill", "target": "void_wisp", "count": 5, "desc": "击败虚空幽灵"},
    {"id": "obj_3", "type": "collect", "target": "star_core", "count": 3, "desc": "收集星核能量"}
  ],
  "rewards": {"exp": 500, "gold": 300, "items": ["star_core_small"]},
  "unlock_condition": {"level": 1}
}
```

### 3.3 任务跨端同步

- 任务进度服务端统一存储
- Web/Cocos 可推进任务进度（日常/采集类）
- Unity/UE 推进主线/深度内容任务
- 多端共享同一任务进度，切换端无损失

## 四、角色体系（跨平台）

### 4.1 角色数据（引擎无关）

```yaml
伊芙:
  定位: 导师/引导者
  性格: 睿智沉稳
  身世: 古代文明后裔
  关键剧情: [序章教导, 第二章身世揭晓, 终章选择]
  立绘: assets/characters/yifu_base.png  # 素材 ID，各引擎适配
  语音: [yifu_intro.mp3, yifu_choice_1.mp3]  # 通用音频格式
```

### 4.2 多端角色表现

| 平台 | 角色表现 | 素材规格 |
|------|---------|---------|
| Web | 静态立绘 + 文字 | 低分辨率 PNG |
| Cocos | 静态立绘 + 简动画 | 中分辨率 PNG + 骨骼动画 |
| Unity | 3D 模型 + 表情动画 | FBX + 材质贴图 |
| UE | 高保真 3D 模型 + 面部捕捉 | 高精度 FBX + 4K 贴图 |

**素材复用策略**：基础立绘/音频通用，3D 模型在 Unity/UE 间共享（FBX 格式），Web/Cocos 用 2D 立绘版本。

## 五、叙事节奏与跨端一致性

### 5.1 叙事节奏设计

- 主线剧情与玩法关卡深度绑定，关键剧情节点触发 BOSS 战/剧情演出
- 支线与日常采用「碎片化叙事」，不打断主线节奏
- Web/Cocos 端每日推送 1-2 段剧情（碎片化），Unity/UE 端完整推进

### 5.2 跨端叙事一致性保障

| 保障项 | 策略 |
|-------|------|
| 剧情内容一致性 | 同一份 JSON 数据，多端渲染 |
| 角色关系一致性 | 角色关系状态服务端存储 |
| 世界观一致性 | 世界观基准文档统一维护 |
| 触发时机一致性 | 触发条件服务端判定，多端同步 |
