## 一、战斗判定引擎无关抽象

### 1.1 战斗逻辑分层

```
┌─────────────────────────────────────────────┐
│  战斗判定层（引擎无关，纯逻辑）              │
│  · 命中判定（数学计算，无物理引擎依赖）      │
│  · 伤害计算（统一数值公式）                  │
│  · 状态效果（Buff/Debuff 状态机）            │
│  · 技能结算（技能逻辑纯函数）                │
├─────────────────────────────────────────────┤
│  战斗表现层（引擎适配器）                    │
│  · 动画播放 / 特效触发 / 音效播放            │
│  · 受击反馈 / 镜头震动                       │
├─────────────────────────────────────────────┤
│  输入层（多端输入适配）                      │
│  · Web/Cocos：触摸/点击                      │
│  · Unity：键鼠/手柄                          │
│  · UE：键鼠/手柄/VR（可选）                  │
└─────────────────────────────────────────────┘
```

### 1.2 帧率无关判定机制

- 战斗逻辑使用**固定时间步长**（如 30Hz Tick），与渲染帧率解耦
- 渲染层插值补偿视觉平滑，逻辑层按固定 Tick 推进
- 高帧率设备（120Hz）获得更平滑渲染，但不影响判定结果

```cpp
// C++ 中间件（引擎无关）战斗 Tick 示例
void CombatTick(float delta_seconds) {
    // 固定 30Hz 逻辑步长，delta_seconds 累积
    accumulator += delta_seconds;
    while (accumulator >= TICK_INTERVAL) {
        ProcessCombatTick();  // 命中/伤害/状态判定
        accumulator -= TICK_INTERVAL;
    }
}
```

## 二、多端输入适配

### 2.1 输入映射抽象

| 战斗动作 | Web（触屏） | Cocos（触屏） | Unity（键鼠） | UE（手柄） |
|---------|------------|--------------|-------------|-----------|
| 移动 | 虚拟摇杆 | 虚拟摇杆 | WASD | 左摇杆 |
| 普攻 | 点击按钮 | 点击按钮 | 鼠标左键 | X/A |
| 重击 | 长按按钮 | 长按按钮 | Shift+左键 | Y/B |
| 闪避 | 滑动方向 | 滑动方向 | Space | 右摇杆 |
| 格挡 | 盾按钮 | 盾按钮 | 右键 | LT/RT |
| 技能1 | 技能图标 | 技能图标 | 1 键 | RB |
| 大招 | 大招按钮 | 大招按钮 | R | LB |

### 2.2 触屏操作增强

- **连击滑动**：滑动方向触发位移技能/闪避，降低触屏操作门槛
- **智能施法**：面向敌人自动瞄准 + 点击确认，适配触屏精度限制
- **虚拟按键自适应**：根据设备尺寸/横竖屏自动布局

## 三、技能与职业设计（跨平台版）

### 3.1 职业体系（引擎无关数据驱动）

```yaml
守望者:
  定位: 均衡输出
  核心机制: 星械变形
  技能: [普攻连段, 星械重击, 闪避突袭, 星核爆发]
  跨平台适配: 全端可用（操作复杂度中）

星匠:
  定位: 坦克/承伤
  核心机制: 护盾/嘲讽
  技能: [重锤横扫, 壁垒护盾, 挑衅怒吼, 大地震颤]
  跨平台适配: 全端可用（操作复杂度低，适合触屏）

织雾者:
  定位: 治疗/辅助
  核心机制: 治疗链/增益
  技能: [织雾缠绕, 生命链接, 净化之光, 星辉降临]
  跨平台适配: 全端可用（操作复杂度中）

虚空猎手:
  定位: 刺客/爆发
  核心机制: 隐身/背刺
  技能: [潜行突袭, 虚空撕裂, 致命背刺, 暗影领域]
  跨平台适配: 全端可用（操作复杂度高，需高精度输入）
```

### 3.2 技能数值锚点（引擎无关）

- 单体技能 DPS ≈ 1.0 基准，范围技能降单体伤害换取覆盖
- 控制技能时长 ≤ 2s，有递减机制
- 大招充能：普通战斗 60~90s 攒满，高风险场景加速
- 技能冷却精确到毫秒，统一由 C++ 中间件管理

## 四、NPC AI 行为设计（引擎无关）

### 4.1 行为树数据结构（纯数据，各引擎解析）

```json
{
  "npc_type": "elite_void_wisp",
  "root": {
    "type": "selector",
    "children": [
      {"type": "sequence", "conditions": ["health<0.3", "in_range"], "action": "frenzy_attack"},
      {"type": "sequence", "conditions": ["player_visible"], "action": "chase_and_attack"},
      {"type": "action", "action": "patrol"}
    ]
  }
}
```

### 4.2 多端 NPC 行为一致性

- 行为树配置以 JSON 存储，各引擎解析执行同一逻辑
- 寻路算法统一在 C++ 中间件实现（A*/NavMesh 抽象）
- NPC 状态机纯逻辑，引擎只负责表现层动画

### 4.3 难度自适应（跨端统一）

- 根据玩家 DPS/生存时长动态微调攻击频率与技能释放
- Web/Cocos 轻量端降低反应要求（AI 攻击前摇加长 20%）
- Unity/UE 完整端保留完整 AI 行为深度
