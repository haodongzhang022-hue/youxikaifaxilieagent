## 一、跨平台数值一致性策略

### 1.1 数值精度统一

| 数值类型 | 统一精度策略 | 实现方式 |
|---------|-------------|---------|
| 战斗数值 | 定点数（32bit，1/1000 精度） | 统一 C++ 中间件实现 |
| 经济数值 | 整数（资源/货币） | 杜绝浮点误差 |
| 百分比加成 | 浮点 → 定点转换表 | 查表法，多端一致 |
| 时间相关 | 整数毫秒 | 服务端时间戳 |

### 1.2 多端数值基准

所有引擎共用同一份数值配置表（JSON/YAML），通过 C++ 中间件加载：

```yaml
# 等级成长曲线（引擎无关配置）
level_curve:
  1:   {exp: 0,    atk: 10,  hp: 100}
  2:   {exp: 100,  atk: 13,  hp: 130}
  3:   {exp: 280,  atk: 17,  hp: 170}
  4:   {exp: 550,  atk: 22,  hp: 220}
  5:   {exp: 900,  atk: 28,  hp: 280}
  ...
```

### 1.3 引擎差异适配策略

| 引擎 | 性能特点 | 数值适配策略 |
|------|---------|-------------|
| Web（React） | 轻量、浏览器限制 | 简化战斗数值（回合/半实时），保留核心成长 |
| Cocos | 小程序快速加载 | 缩短战斗时长（节奏加快），适配触屏输入 |
| Unity | 完整内容 | 全量数值体系，完整战斗系统 |
| UE | 高质量高保真 | 全量数值 + 高级特效数值（伤害计算精度提升） |

## 二、经济系统模型（跨平台版）

### 2.1 多端统一经济

- **统一货币体系**：金币（基础）、星核（高级）、蚀潮石（活动限定）
- **跨端互通**：服务端统一账本，多端共享资源
- **端差异化投放**：Web/Cocos 侧重引流轻量投放，Unity/UE 侧重深度养成

### 2.2 产出/消耗闭环

**产出**：
- 战斗产出：胜利结算 → 金币 + 材料（掉落表驱动）
- 任务产出：任务奖励 → 金币 + 经验 + 特殊道具
- 日常/活动：限时产出 → 调节经济节奏

**消耗**：
- 成长消耗：升级费用 + 技能强化 + 装备锻造
- 系统消耗：抽取 + 交易税 + 体力恢复
- 防膨胀：每日产出上限 + 消耗锚点 + 资源回收机制

### 2.3 数值平衡区间

| 指标 | 目标区间 | 说明 |
|------|---------|------|
| 产出/消耗比 | 0.85~1.15 | 防通胀/紧缩 |
| 日活跃产出 | 玩家日产上限 | 控制资源流速 |
| 成长曲线拐点 | 30级前后 | 前期快感+后期长线 |
| 付费/免费差距 | ≤ 30% 战力 | 不拉开绝对差距 |

## 三、成长曲线（多端统一）

### 3.1 等级成长

```
1-30 级：快速成长（新手期爽感），约 2-3 天
30-60 级：放缓（中期长线），约 1-2 周
60 级+：深度养成，约 1 月+（配合赛季）
```

### 3.2 战力增长模型

- **基础成长**：等级 + 装备 + 技能（线性 → 指数）
- **百分比加成**：装备套装 + 养成系统（叠加乘区）
- **峰值控制**：版本内容开放节奏限制战力天花板

### 3.3 跨端成长同步

- 账号数据服务端统一存储
- 多端登录共享成长进度
- Web/Cocos 轻量端可玩日常/采集/社交，Unity/UE 完整端可玩深度内容
