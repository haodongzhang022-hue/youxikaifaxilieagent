# wp_numeric_model · 数值/经济/成长曲线模型

- **工作包**：wp_numeric_model 数值/经济模型设计
- **部门**：策划线
- **主责角色**：balance_designer（数值策划·理性派）
- **模块**：numeric_model
- **产出物类型**：numeric_table（数值表）

## 一、经济系统模型（economy）

**产出循环**：
- 战斗/任务/日常产出基础资源（金币、材料）
- 材料通过「合成/升级」消耗，形成产出→消耗闭环
- 引入稀有度分级与限量资源，控制产出节奏防止膨胀

**消耗循环**：
- 成长消耗：升级、技能强化、装备锻造
- 系统消耗：抽取、交易税、生活系统
- 防膨胀设计：设置每日产出上限 + 消耗锚点

## 二、成长曲线（growth_curve）

- **等级曲线**：前 30 级快速成长（新手期爽感），30 级后放缓（长线目标）
- **战力曲线**：随等级/装备/技能叠加，非线性增长，峰值随内容开放
- **资源曲线**：单位时间产出随玩家等级提升而增加，但增速低于消耗增速，引导长期投入

## 三、平衡性数值（balance）

- **战斗平衡**：输出/承伤/治疗/控制四维做差值模型，保证多职业平衡
- **经济平衡**：产出-消耗比值控制在 0.85~1.15 区间，防止通胀/紧缩
- **付费平衡**：免费玩家靠时间，付费玩家靠效率，不拉开绝对战力差距

## 四、市场预演输入（供运营线消费）

- base_quality=65.0（基础品质分）
- arpu=2.5（平均每付费用户收入）
- competition=0.4（市场竞品压力）
- monetization: iap_depth=0.5 / iaa_density=0.25（IAP/IAA 双轨）

> 产出：数值策划 balance_designer 承接，产出后经 market_input_bridge 转译给运营线做市场预演。
