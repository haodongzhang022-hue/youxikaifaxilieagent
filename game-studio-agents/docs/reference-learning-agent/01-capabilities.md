# 01. 能力模块定义（Capabilities）

Agent 的能力按"理解 → 迁移 → 落地"三层组织，每层再细分若干原子能力。所有能力都可独立开关、独立评估成熟度。

## 1. 理解层（L1：Game Comprehension）

| 能力 | 说明 | 输出物 |
|------|------|--------|
| 玩法机制识别 | 从素材中识别核心玩法（如采集/建造/战斗/解谜/社交） | 机制清单 |
| 系统拆解 | 将目标游戏拆为系统树（经济、成长、战斗、社交……） | 系统结构图 |
| 数值与经济循环还原 | 分析数值曲线、资源产出/消耗循环、成长节奏 | 数值模型 |
| 心智模型还原 | 理解玩家动机（心流、收藏、竞争、协作）与情绪曲线 | 动机画像 |
| 视觉/交互语言提取 | 提取 UI 布局、动效、美术风格、反馈节奏 | 视觉规范摘录 |

> 输入源（Input Sources）：游戏视频、玩法图文、设计文档、开源代码、玩家社区反馈、截图序列。

## 2. 迁移层（L2：Reference Transfer）

| 能力 | 说明 | 输出物 |
|------|------|--------|
| 适配度评估 | 评估该机制与自有游戏类型/受众/技术栈的契合度 | 契合度评分卡 |
| 取舍裁剪 | 识别可整体搬、需裁剪、需改造、应放弃的要素 | 取舍矩阵 |
| 融合设计 | 将外部机制与自有游戏现有系统融合，避免割裂 | 融合方案 |
| 创新点挖掘 | 在借鉴基础上提出差异化创新，避免纯抄袭 | 创新提案 |
| 合规与风险审查 | 判断版权/专利/合规风险，剔除高风险借鉴 | 风险报告 |

## 3. 落地层（L3：Mod Implementation）

对应"创意工坊模组"能力，这是本 Agent 区别于"仅做分析"Agent 的关键差异点：

| 能力 | 说明 | 输出物 |
|------|------|--------|
| 视觉改造 | 调整/替换 UI、配色、图标、动效、镜头语言 | 视觉资源 + 样式配置 |
| 展现方式改造 | 改变信息呈现（HUD、弹窗、引导、叙事呈现） | 展现配置 |
| 功能模块开发 | 新增/修改玩法逻辑、数值系统、事件循环 | 功能代码/配置 |
| 模组打包 | 将改动封装为可插拔 Mod（含 Manifest、资源、配置） | `.mod` 包 |
| 预览与沙盒验证 | 在隔离环境试运行 Mod，验证无破坏 | 验证报告 |
| 开关与回滚 | 支持运行时开关、一键回滚到主游戏基线 | 版本/快照 |

## 4. 能力成熟度分级

每个能力从 **Level 0 → Level 3** 分级，便于迭代：

- **L0**：不具备（需人工完成）
- **L1**：可辅助（提供分析/草稿，人工确认）
- **L2**：可执行（自动生成，自动校验，人工审核后合入）
- **L3**：可自治（自动生成并自动合入，仅告警不阻塞）

> 默认推荐配置：**理解层 L2、迁移层 L2、落地层 L2**（保持"人工可兜底"，后续按信任度升级）。
